Place eight queens on the 8x8 board described by `board.json` in the working directory so that no two attack each other, honouring the cells that file marks as blocked. Write the answer beside it as `solution.json`: a list of eight column indices, one per row, row 0 first. The checker `check_queens.py` in the same directory validates a solution file (`python3 check_queens.py solution.json`); run it before you finish.
