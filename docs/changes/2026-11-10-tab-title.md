ledger+: terminal tab | the title is `Yi`, a state mark, and the session summary, with `>` while idle
---

The terminal tab reads `Yi > <summary>` while the session is idle, `Yi ! <summary>` while it is waiting on you, and `Yi ◌ <summary>` while it works. The four-frame pulse stays `◌ ◍ ◉ ◍` every 250 ms. The summary is the session name. After the first turn the summarizer names the session the way omp's title fork does: the model chooses an emoji and a short code for that session, and the stored name is `🧪 FLAKY: Fix flaky park tests`. A session with no name still shows `Yi >`. A session that already has a name keeps it.
