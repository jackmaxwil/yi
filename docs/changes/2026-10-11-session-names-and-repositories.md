`history://` now reaches every session you have on this machine, not only this repository's (Closes #1244). A root session reads by its id in any repository, or by its name: `history://forge-root/tail/40` finds the session named `forge-root`, this repository's first, then another's. A child reads as `history://forge-root/worker-3`, found through the spawn record its root keeps. A name two sessions share is refused with both files listed, so you read one by its id. A reader under a history wall, which names sessions by id, resolves no name and no `root/child`, so an alias can never reach a transcript its wall refuses. Session search stays this repository's. A session header whose directory was spelled through a symlink (`/var` for `/private/var`) is now recognized as this repository's.
