A `--faux` cassette can carry real timing, so a motion scene shows the cadence a person sees (Closes #1265). A cassette line may now be a line of a recorded session file: its assistant messages replay, each over the time its entry landed after the message that prompted it (the user's, or the last tool result), split evenly over the reply's deltas. A bare message per line still replays instantly, so no existing cassette changes. On a live run the delay is wall time; under a drive script with `tick` the provider keeps virtual time that `tick` advances in step with the app clock, and the drive waits, before and after each 16 ms step, until the model request the loop announced exists and every stream event the provider sent has reached the screen's queue, then reduces the step once, so two runs of a frozen scene draw the same cells. A frozen paced stream is not held by `hold`. `scripts/proof/tui_see/paced.drive` replays a reply cut from a scrubbed real session (7.7 s on the wire) as a four-frame strip.
