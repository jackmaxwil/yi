Middle failures survive output reduction (Closes #1153). When long command output is shortened, an error or failure in the cut middle is now kept with three lines either side, runs of passing tests collapse to one counted row, and grep shows at most three matches a file with a row naming the rest. pytest's verbose lines no longer overwrite each other as if they were a progress bar.
