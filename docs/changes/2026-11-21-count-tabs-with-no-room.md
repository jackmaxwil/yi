In Yi Desktop a pane bar too narrow for every tab of its stack now draws the tabs nearest the pane in front and counts the rest in a `+N` chip, which opens the Panes panel where each can be brought in front. Three tabs in the 208-point side column were squeezed to an icon before. The tab keys still reach every tab.
