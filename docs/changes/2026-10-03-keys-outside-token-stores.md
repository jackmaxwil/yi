Keys kept beside yi's token stores stay away from the model (Closes #906). The MCP session store, which keeps each stdio server's `env`, is now refused to read, grep, globs, edit and write however it is spelled, a hard link in the working directory included, and a bash command naming it asks first. Bash and the kernel no longer inherit yi's provider key variables (`ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `OPENROUTER_API_KEY`, `GEMINI_API_KEY`, `LAYA_API_KEY`), contained or not, so `printenv` in yolo mode or on a host without a sandbox prints none of them. `~/.yi/oauth` was already a credential store.
