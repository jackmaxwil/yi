The model can ask to close a todo whose check cannot run, and the user or the classifier answers (Closes #954). A contract item the verifier could not run left the model no way out: the `accept` that lands `Done { AcceptedByUser }` was reachable only from the CLI and the console, and the CLI passes no confirmer. The plan tool now takes `accepted_by_user` (or `accept`) with a `note` saying what was run by hand; the user sees a permission prompt naming the todo and the note, and in auto mode with the classifier configured an allow from it settles the acceptance alone, recorded as `classifier` and landing `Done { AcceptedByClassifier }`, never as the user's. A checker timeout's refusal now names that call.
