A review round reads only the PR's own change, and a silent lens no longer voids it (Closes #920, closes #1004). Round two onward read from the last clean head to the new head, so a branch that had merged main in between put main's commits in the lens's diff and blocked on other PRs' code (#911's round 3 on #913's test). The round now diffs the fork point to the head (`origin/main...HEAD`), and after a clean round keeps only the paths both touched since it and in the PR's own change, so "what changed since" survives a merge of main without main's work; the lens prompt names that range. A lens or refuter that stays unanswered after the existing repair retries (a reply on stdout that is not JSON, or a hung `yi ask`, included) is named in the round and counted in its meta line as `skipped=N`; such a round is no base for a later delta and does not make the PR ready. A finding whose refuters all stayed silent is kept and marked unverified, one whose answering refuters broke it is dropped. Only a round with every lens silent still posts nothing, as on #733.
