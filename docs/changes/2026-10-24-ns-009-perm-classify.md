Yolo's destroy belt now reads every segment of a command. It used to read only the first word of the whole string, so `cd build && rm -rf ~/.ssh`, `true; rm -rf .git` and `echo done && rm -rf ~` ran in yolo although the yolo prompt promises catastrophic targets are always denied. The belt now splits where a shell may start another command (`;`, `&`, `|`, a newline, a parenthesis, a backtick) and judges each segment that runs `rm`, `rmdir`, `shred` or `unlink`. It splits the raw text rather than taking the classifier's segments, because the lenient splitter strips a leading `$` and would stop `$HOME` from expanding to the home directory. On macOS the destroy gate also compares paths with letter case folded, since a default volume opens `~/.SSH` as `~/.ssh`; folding both sides only ever denies more.

Auto mode's classifier now reads flags the way the programs do. A short flag counts anywhere in its cluster, so `git clean -df`, `-xdf` and `-fxd`, `git checkout -f` and `git switch -f` ask, as do `git checkout .` and a `./` path. A wrapper's own flags (`nice -n 5`, `timeout -s KILL 5`) and an environment assignment (`FOO=1`) no longer hide the program they run: every later word is read as that program and the worst reading wins, so `nice -n 5 rm -rf x` and `FOO=1 rm -rf x` ask, and nothing behind such flags or an assignment is proven read-only. Programs the classifier proved read-only stop being proven when a flag or script runs a program or writes a file. `fd -x`, `fd -X`, `fd --exec`, `rg --pre`, `rg --hostname-bin`, `sort --compress-program`, `find -okdir`, `find -fprint` and `find -fprint0` ask, like `find -exec`. `sed` with `i` in any cluster or with `w`, `W` or `e` in its script, `awk` with `system`, a pipe, a `>` or `-f`, `sort -o`, `tree -o`, `uniq` with two operands, `git --output` and any `git -c` or `--config-env` are contained, like `sed -i`. A long flag counts by any prefix, since getopt takes `--out` for `--output`. An ask or containment now names the program behind an assignment, so `FOO=1 rm -rf x` reads "`rm` is destructive", not "`FOO=1` is destructive". The cost is that more commands are contained or ask in auto: an awk filter comparing with `>` or matching `a|b`, a sed script with a backslash, `git -c color.ui=always log` and `uniq -f 1 in` are now contained where they ran, which off macOS means they ask. Member units: HA-PERM-belt, HA-PERM-classify.
