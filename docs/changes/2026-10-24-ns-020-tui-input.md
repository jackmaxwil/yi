A paste reaches the model as the person pasted it. The composer used to rewrite a paste before storing it, turning every tab into three spaces and dropping every other control character, so a tab-indented Makefile recipe or a terminal capture with colour escapes arrived as different text. It now keeps the bytes and only turns CR and CRLF line endings into LF; the box draws a tab as four spaces and a control as its one-cell picture, and wraps and moves the cursor by those widths. A paste while a question card, a popup or a tree is open goes to that view's text field (one line, whitespace runs become a space) instead of the composer hidden behind it; a card showing options has no field and swallows the paste, so a pasted `2` or `s` is never taken for the key that answers. The test that pinned the rewrite is replaced by one that pins the bytes. Unit HB-tui-paste.
