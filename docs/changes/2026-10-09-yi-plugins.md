`yi plugin add ripwire` downloads ripwire 0.6.5 for macOS on Apple silicon or Linux (arm64, x86-64), checks it against the sha256 compiled into yi before unpacking it, and installs the one binary into `~/.yi/plugins/ripwire/0.6.5/`. Ripwire's bundled skills and hooks are never unpacked. `yi plugin list` shows each plugin's state, `remove` deletes it, `add --all` installs every plugin, and `sync` brings the ones you installed up to the version this yi pins. Yi uses its own copy first, then a ripwire on PATH; a copy at another version on disk is ignored, and `yi doctor` and `yi plugin list` both name `yi plugin sync` for it. The model's bash, the kernel's `bash()` and the edit check all find the installed copy by name, so the ripwire card's commands work without it being on the user's PATH. The uv bootstrap now shares the same download-and-verify code. CI and the eval containers follow in a separate change (#1041); the first-launch setup offer waits on the paired eval (#1019).
