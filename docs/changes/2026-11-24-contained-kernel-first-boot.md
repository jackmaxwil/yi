A contained kernel on Linux boots on its first `ipython` call. Its Landlock profile names only paths that exist when the profile is built, and the profile was built before the bootstrap made the venv and the kernel's connection dir, so a first boot could not exec its own python and the cell failed with "Kernel exited before resolving ports". The kernel now bootstraps and makes its connection dir before its profile is built. On Linux a contained kernel also gets `IPYTHONDIR` inside that connection dir, because under Landlock access(2) still reports a read-only home as writable and IPython would try to create `~/.ipython` there. It keeps the system temp dir as `TMPDIR` whenever its profile may write there; only when that root holds a denied store (a home inside it, as in the test harness) and so is granted only as its children does `TMPDIR` move to `tmp` in the session's kernel state dir, which a kernel restart keeps. The postmerge journey that mails an evicted session now waits for its sending cell to finish and fails with that cell's own error, and a new journey checks that a file in the kernel's temp dir outlives a kernel restart.
