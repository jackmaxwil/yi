The todo tool no longer refuses a stale view or a checklist that marks a row done (Closes #1075). A call sent with an old `touched` counter is applied to the list as it is now, and a whole-list `set` from that view keeps the rows it did not mention, so a row the user added is never lost; a `set` that marks a row done keeps it open, since closing a row takes `done` with its evidence. Each of these says so in a `note:` line, and the rest of the call lands.
