A kernel program now gets data, not only text, from the tools it calls (Closes #1243). `yi.tools.grep(...)` returns every hit as `value.matches` (path, line, the whole line), past the model's 2,000-match page; `yi.tools.read(...)` returns the asked window or the whole file as numbered lines with the tag an edit cites, and a program can edit any line it returned, while the model still edits only lines it was shown. A directory, a glob, `edit`, `write`, `bash` (the streams before the reducer shortened them), `get_context`, `todo`, `annotate`, `plan` (the plan document after the op), an address, a child's `ask_user` and an exec tool each hand back their own shape. A value is never written to the session file, and one past a program fuse (64 MiB, or 100,000 lines, matches or files) says so in its `cut` row, naming the call that gets the rest.
