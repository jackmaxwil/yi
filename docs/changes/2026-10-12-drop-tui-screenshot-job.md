No CI job plays the TUI scenes any more. The `tui` workflow, which built the base and head binaries and posted before and after screenshots on every pull request touching the TUI, is gone, with its live gallery release. The review bot no longer waits for that comment, so a round on a TUI pull request starts reading as soon as its job does. `just tui-see` still runs the scenes locally (`run`, `diff`, `gallery`, `watch`, `harvest`, `monkey`, `--host term`).
