A scene can now be played in kitty and WezTerm as well as Ghostty, so kitty graphics, OSC sequences and colour tiers are seen working in each terminal Yi claims rather than assumed. The yi-term image adds Ubuntu's kitty package and WezTerm's official Ubuntu 22.04 build pinned by sha256, and is tagged by its Dockerfile's hash so sessions sharing one Docker daemon each run the image their own tree built. `tui_see.py run --host term --terminal ghostty|kitty|wezterm` picks the terminal, and every term run prints what the terminal advertised (`TERM`, `COLORTERM`, `TERM_PROGRAM`, `KITTY_WINDOW_ID`), the colour tier Yi wrote, read off its SGR forms, the kitty image ids it placed by family, and each OSC number it sent. `tui_see.py terminals <scene>` plays one scene in all three and writes one comparison sheet: that table above the grabs side by side. iTerm2 is macOS-only, so the sheet carries a `[…]` row saying it was left out and whether it is installed. The CI image on the infra repository is unchanged; this is a local check.
