In Yi Desktop, hold ⌘ and click a file to open it beside the code viewer in a pane of its own, or hold ⌥⌘ to open it in a window of its own. Each code pane now shows its own file: the pane beside keeps the file it was opened for while the viewer moves on. Split on the code viewer puts the file it shows beside it the same way; before, the second pane showed whatever the first did.
