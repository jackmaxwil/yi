Four crates each carried their own base64 encoder: the console's OSC 52 copy string, the orb's kitty transmit payload, ACP's terminal output chunks, and the URL-safe unpadded form oauth uses for the PKCE S256 challenge. They now share crates/types/src/encoding.rs, which holds `base64` (standard, padded) and `base64url_nopad` (URL-safe, unpadded) over one loop, pure and dependency-free like `image::is_strict_base64` beside it. yi-orb was a leaf with no internal dependencies, so it now depends on yi-types; scripts/guardrails/boundaries.toml, the crate table in docs/YI_DESIGN.md section 2 and the crate map in docs/ARCHITECTURE.md name the new edge. The orb's test-side decoder in crates/orb/tests/kitty.rs stays, since an independent check of the encoder is its point. ACP's own padding test went with its copy, because the yi-types test now covers every tail length against Python's base64 module and the RFC 7636 appendix B challenge. Every string these encoders emit is byte-identical to before: the console OSC 52 test, the orb kitty tests and the ACP chunk test pass unchanged.
