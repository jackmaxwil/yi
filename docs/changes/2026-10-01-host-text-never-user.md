Host text never reaches the model as the user's words (Closes #966). Job reports, child lifecycle notices, the mail chase, landing failures, turn-cap and last words, plan-store and rule-warning notices, the kernel restore block, eleven custom nudge and notice kinds, the summaries and the environment block all arrived as bare user-role text, and a model answered them as "User asks". The converter every request passes through now keeps bare only the user's typed words, a session's task (a child's brief, a reviewer's or one-shot prompt) and messages from before attribution existed; everything else arrives fenced as runtime context under the name of what produced it. A message's attribution now says `task` or `host` with its source, and the TUI draws host text as a flagged notice as before.
