A console that starts with no session now opens on a title animation instead of a blank pane, and an empty session draws the same field under its composer. The scene is drawn once per console start by weighted chance: the Kali fold eight times in ten, the echo rings two, seeded from the clock. The fold opens from a deep zoom over three seconds, turns once every sixteen, and the `Yi` strokes rise through it from second 2.4 to 3.4 and stay solid; the first message ends it. Interactive consoles play it by default; a headless drive keeps it off unless the config asks, so its frames hold still. `console.titleIntro` turns it off and `console.titleWeights` (scene name to weight, `{"kali": 1}` pins one, a weight of 0 turns a scene off) sets the odds; an unknown scene name stops the console naming the key. Both are rows on the settings page, applied at the next console. The field is a pure function of the free rows' size, a scene and the seconds since the console started, `yi_tui::title::paint`, so a frozen clock replays any frame; the strokes are the orb's own `MARK_STROKES` constant, now shared. The console asks for a frame every 50 ms only while a title is on screen. Tests pin the signed distance at five points computed by hand from the stroke constants, the solid stem at 80x24 and 200x50, an empty first instant and a solid name once the fold has opened, exact loops for both scenes, the draw's odds at 20,000 seeds, and that the chat's own four rows are never touched; each was seen red against a mutated field. `tui_see` scenes can set config with `--config '<json>'` in their header, and `scripts/proof/tui_see/title.drive` plays a cold start with the fold pinned on a frozen clock.
