An empty, idle console session can now draw a title field under its composer: rings spread from the strokes of the `Yi` mark, the strokes stay solid, and the first message ends it. It is off until `console.titleIntro` is set (a row on the settings page, applied at the next console). This is stage 0 of the fullscreen title: the field is a pure function of the free rows' size and one elapsed time, `yi_tui::title::paint`, so a frozen clock replays any frame; the strokes are the orb's own `MARK_STROKES` constant, now shared. The console asks for a frame every 50 ms only while a title is on screen. Tests pin the signed distance at five points computed by hand from the stroke constants, the solid stem at 80x24 and 200x50, a faint far field at every time, a loop that closes without a seam, and that the chat's own four rows are never touched; each was seen red against a mutated field. `tui_see` scenes can now set config with `--config '<json>'` in their header, and `scripts/proof/tui_see/title.drive` plays the field in a real console.
