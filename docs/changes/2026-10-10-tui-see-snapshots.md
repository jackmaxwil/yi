A drive script can now name the moments worth looking at: `snap <name>` keeps the frame drawn at that step as a still cast and a text dump, beside the frame dumps, on both the solo and the console drive. `just tui-see run <scene> --label base`, an edit, `just tui-see run <scene>`, then `just tui-see diff <base> <head>` prints what changed: every changed row with its before and after text and its style changes (`cols 0-0: fg=idx6 → fg=idx5`), the changed regions, and crops of each region before and after rendered with agg. A scene's setup rides its `#!` line (`#! solo --size 80x24`, `#! console --size 120x34`, `--seed <session.jsonl>` to start from a real session). A still cast no longer replays the cell a wide symbol covers, which had pushed the rest of the row one column right in every agg still after a CJK glyph. A frame dump that fails to write on the console drive is now an error, as it already was on the solo drive, and a repeated snap name is refused rather than overwriting the first frame.
