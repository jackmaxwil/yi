Yi now cleans up its checkpoint repos (Closes #1124). A project's shadow repo under `~/.yi/checkpoints` is deleted once the project has been gone a week; a project that cannot be read, or that sits on a volume that is not mounted, keeps its repo. In a project that still exists, snapshots older than 30 days are pruned and every younger one is kept whole, including a snapshot of a project nothing changed in. The sweep runs about once an hour from session start. `yi gc` shows what it would remove and trim, and `yi gc --fix` does it now. The old unhashed `~/.yi/kernel-venv`, which the venv sweep never matched, is now removed with the other stale venvs. On the machine that found this, the preview counted 11,510 of 11,658 repos to remove and 2 to trim.
