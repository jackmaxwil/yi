The TUI scenes now cover the views a TUI change most often moves (Closes #1260, Refs #1160). Eight scenes join `empty`, `typed`, `reveal`, `paragraph` and `ws-term` under `scripts/proof/tui_see`: `tool-cell` (a read cell and a bash cell), `edit-card` (an edit with its diff), `permission` (an edit held at the gate, then refused, under `--confirm`), `todos` (the HUD list with done, blocked and dropped rows), `kernel-cell` (a resumed session holding a stdout cell and a traceback cell), `markdown` and `markdown-narrow` (one long reply with headings, nested lists, a table, a code fence, a quote and a task list at 100 and 56 columns), and `rail` (the console rail and its sidebar with three answered sessions). The scenes that run tools use a frozen clock, so tool durations, spinner frames and the footer's elapsed time do not move between runs; the console scene keeps the random-id colour noise that every console scene has. `kernel-cell` replays a session seed recorded by a real run instead of booting the kernel, whose cell durations are wall time the frozen clock cannot hold. Their files live in `scripts/proof/tui_see/files` and beside each scene as `<scene>.jsonl`.
