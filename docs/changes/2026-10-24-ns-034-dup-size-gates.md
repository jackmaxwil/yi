The duplication gate now reads prompts and shipped skills as well as Rust. It scanned only `crates/*/src/**/*.rs`, although the guardrail rules said production duplication covers prompts; it now also scans `crates/*/src/**/*.md`, `skills/**/SKILL.md` and `python/skills/**/SKILL.md` with a 6-line window, and skips the `yi:schema` blocks that are rendered from a tool's schema and so repeat by design. It catches prose copied between prompts and skills; a skill that restates a tool description held in a Rust string or a schema block is still not refused, so the skills rule's promise of that stays unenforced. Today's tree has no prose copy that long. Its new `--selfcheck` plants a 15-line Rust copy, a 6-line copy across two skills below a schema block, one-line-shorter copies, test code under `#[cfg(test)]` and a repeated schema block, asserts each hit names its line in the file, and fails if either file set, the test cut, the schema skip or a window width is switched off.

The dist binary size gate passes growth up to a fixed 16,384-byte jitter allowance past its baseline, chosen because 71 of 150 ratchet commits moved it by 256 bytes or less, so a build that moved by a few bytes no longer writes a `Ratchet:` commit; one byte past the allowance still fails, and the push verb then records the measured size, so the unrecorded gap never exceeds the allowance. Raising `HARD_CAP_BYTES` in `check_binary_size.py` now fails unless a change file on the branch carries a `decision:` line, read from the script's own text at the fork. The forge's guardrails lane now builds the dist binary on Linux and holds it to a new `binary_size_budget_linux.json`; startup stays off the forge, and a CI run on any other host still skips both. The forge's first run measured the Linux binary at 13,220,280 bytes, past the 9 MiB cap, so Linux is held under its own `HARD_CAP_LINUX_BYTES` of 14 MiB, which the same `decision:` check guards, and its baseline is that measurement. YI_DESIGN.md §18.6 and §21 say so. Units: B4-dup-gate-prose, HD-G03-size-gate.
