A Python program can fan out Yi's subagents itself, with no model turn at the root (Closes #981). `python/yi_client.py` is one standard-library file: `Yi(cwd, model=…)` starts `yi acp` on stdio and opens a session, `run` executes code in that session's kernel through the existing `_yi/kernel_execute`, `eval` returns an expression's JSON value through a file so the 64K output cap never cuts it, and `ask`/`ask_all` wrap `rlm.ask` and `asyncio.gather`. Children spawn and are recorded exactly as from a model-run cell. In the swarm dogfood the root's own model turns, which only ran one cell, were 10 to 60% of a run's cost and could alter the cell; this removes both. A permission ask is answered `reject_once`, since nobody is there to approve it. The protocol already carried everything; the one runtime change is that a child finishing under a client's cell no longer wakes the idle root into a model turn, which the journey caught consuming a scripted reply meant for a child.
