A justfile was the one cheap source of tools every repository already had, and reaching it cost a `bash` call the model had to spell from memory: `yi tool import just` now dumps the project's recipes with just's own `--dump --dump-format json` and writes one exec-tool wrapper per recipe into `~/.yi/tools`, the directory `session_tools` already scans. The schema is the recipe's real parameters — a default makes one optional, `*` and `+` become an array of strings — and the doc comment is the description, so the model reads the signature just enforces instead of guessing it.

A call reaches the recipe as an argv array built from the JSON the exec-tool contract hands the wrapper, never through a shell string; the argument carrying a space and a quote arrives as one element, a literal default is sent in its own position, an omitted computed default is left for just to fill, and a later supplied value is refused rather than shifted into that gap. Every imported recipe stays an `exec` tool: a repository-authored doc marker cannot turn a shell body into an unprompted read. `yi: skip` and `[private]` leave a recipe out and are named in the run's output, and a recipe whose name is a built-in tool's is refused by that name before anything is written. Each wrapper's second line is a marker naming its justfile and recipe: a rerun reports `added`, `updated` and `unchanged`, deletes the wrappers it wrote for recipes the justfile dropped, refuses the whole import when another justfile holds a name, and never deletes or overwrites a hand-written tool or a file it cannot read as text.

A wrapper for a recipe with parameters is `/bin/sh` around a `python3` one-liner that maps the call's JSON to argv, so it needs `python3` on PATH and says so by name when it is missing; a machine with only `uv` still imports, and the wrapper's own `--schema` path needs nothing. A recipe with no parameters needs no interpreter at all and execs `just` itself, which is the common `build`/`test`/`lint` case. The skill `tool-import` is where Yi is taught the command, the wrapper's schema and the skip marker, its catalog line carrying the usage.
