A command that ran and failed, and a refusal that is a rule's answer, now reach the model as results rather than errors (Closes #1072). A failing test run, a refused dependency cycle or a `done` whose check fails was flagged `is_error`, which the model read as a tool fault and retried; only a call Yi could not carry out (refused arguments, a cancelled or timed-out command, a sandbox or safety refusal) is still an error. The model reads the exit code and the refusal text as before, and the TUI card and ACP status still show such a call as failed.
