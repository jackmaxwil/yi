The contributor guide now walks a GitHub contributor from fork to draft pull request with plain git and GitHub, since the forge's push and PR recipes do not work from a mirror clone. It says what to send the owner first, that the pinned email must match case and all, which tools the recipes need, how to check every commit's signature, identity and whitespace before pushing, the caps, paths, dependency edits and added-line content the importer refuses, that the owner supplies the issue number and runs intake, and that some guardrails fail on a mirror clone by design.
