The contributor guide now walks a GitHub contributor from fork to draft pull request with plain git and GitHub, since the forge's push and PR recipes do not work from a mirror clone. It says the pinned email must match case and all, how to check every commit's signature and identity before pushing, which paths the importer refuses outright, that the owner supplies the forge issue number, and that some guardrails fail on a mirror clone by design.
