Contained commands on Linux now run under Landlock. A contained command starts as `yi __contain`, which restricts itself and execs: writes reach its roots, reads reach the system roots, home past the credential stores, and its writable roots. A kernel that refuses the ruleset makes `Contain` an ask, as a machine with no sandbox did before.

Landlock only grants, so a `config` inside a writable root cannot be denied. The host saves what its next git reads when it builds a profile, compares before each of its gits, puts back what changed and refuses that one call. There is no network wall on Linux. A lane's own branch stays writable under `yi/`; any other branch and `git stash` refuse, since neither leaf has a parent the rules may name.
