The Files tree was a modal popup over the panes, and opening a file replaced the focused pane, so a lone chat was swapped for the file and filled the screen. It is now a VS Code style explorer on the right edge, folders before files with indent guides and refresh and collapse-all buttons in its title row, that stays up while a file opens in a panel beside the chat. A click on a folder row folds it, a click on a file row opens it, the wheel scrolls, and the row under the pointer lights up. A press on a pane hands the keys back, and ✕ or Esc closes the tree. A second file reuses the editor panel when its edits are saved and splits a fresh one when they are not, so a file never replaces unsaved work. The cap notice wraps inside the narrow sidebar instead of clipping.

An empty chat and an empty notebook were a blank rectangle. Each now draws a centred start screen: the keys that start work, as click targets, and in a chat the five newest named sessions with their age. It disappears with the first row of transcript, and a replayed session never shows it.

Panels move by zone. ⌘⌥⇧ with an arrow takes a half of the screen, ⌘⌥ with d, f or g a third, and a drag from a pane title, a session row or the new-session control lights the zone under the pointer and drops a panel there. Ghostty binds ⌘⌥ with an arrow to `goto_split` and ⌘D, ⌘F and ⌘G to its own split and search, so the arrows add ⇧ and the letters add ⌥ and none of them reach a chord Ghostty keeps.
