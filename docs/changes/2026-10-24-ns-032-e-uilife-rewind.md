A rewind is refused while a turn is running, in one place (Closes #1470). `rewind_to` re-attaches the session store, which replaces the history a running turn is writing, and only the `files: true` form of ACP `_yi/rewind` checked for a running turn. The solo `/tree` could be opened mid-turn and its rewind went straight through, as did `_yi/rewind` without `files`. The check now lives in `rewind_to` as `ensure_idle` and answers `the current turn is still running`, so every caller, a console pane included, is covered. The `files` form still asks first through the same function, because it restores files before it calls `rewind_to`, and a restore under a running turn cannot be taken back. The solo TUI, whose rewind never touches files, now says so when it applies a rewind: `conversation rewound; files stay as the abandoned branch left them; /undo restores the last turn's edits`. A console pane adds no such notice, since its menu already asks whether the files go too. Crate acp shrinks by 5 lines against the fork.
