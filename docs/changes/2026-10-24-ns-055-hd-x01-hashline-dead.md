The edit tool's hashline module sheds what nothing reaches. Of `prefixes.rs` only `is_read_metadata_line` has a caller, so the other ten helpers, which called only each other, are gone. `mismatch.rs` loses its three line-reference helpers, `tokenizer.rs` loses `parse_lid`, `format.rs` loses seven constants and four formatters, and `messages.rs` loses five constants and `write_drift_warning`. Five fields that were written and never read are gone: the `index` of every `Edit` variant with the counters that fed it (`edit_index` in the parser, `synth_index` in the clipboard and block passes), `block_start` and `old_assertion`, `ResolvedBlocks.resolutions` with its `BlockResolution` type, and `Snapshot.recorded_at` with the store's clock. `OnEmptyPaste` had one live value, so the enum, its three unreachable `Drop` branches and the `Option` that `read_register` wrapped around its result are removed. The block resolver is always supplied, so `resolve_block_edits` takes it directly and the "no block resolver configured" refusal is gone.

Eight hashline modules that only the crate reaches (`apply`, `blocks`, `clipboard`, `mismatch`, `patcher`, `prefixes`, `rebase`, `snapshots`) are `pub(crate)` now, which is what lets the compiler's dead-code lint name any helper left unused in them. In the tools crate root, `outcome_note`, `clamp_timeout` and `ExecTool` are no longer re-exported, and `Sandbox::policy` and `Sandbox::params` are removed (the sandbox tests read the same policy text and `-D` bindings off `Sandbox::wrap`, which is what the sandbox is actually handed). The comment above the edit result's `ops` counts, which promised register economics the keys do not record and named its question only by an id, is deleted; the keys are unchanged.

One claim of the haul did not hold at this head and was skipped: `FLAT_SPILLS` is read by `spill_roots_and_stores` in the runtime crate, so it keeps its re-export. `is_read_metadata_line` is kept as the one live helper in `prefixes.rs`, but no test in the crate reaches it: neutering it leaves every suite green, and the footers it recognises are not the ones the read tool prints today.
