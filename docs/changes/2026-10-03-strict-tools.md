Tool calls are decoded against the tool's schema where the provider enforces it (Refs #995). Yi sent every tool with `"strict": false`, so a model could invent a key or send the wrong type and Yi could only refuse or repair the call afterwards. Each tool schema is now converted at the transport into the shape strict decoding takes: OpenAI's own API gets it for every tool that converts, a Claude from 4.5 on Anthropic's API gets it within that API's per-request caps, and an OpenRouter or other entry opts in with `compat.strictTools`. Eight of the ten tools a session sends convert today; plan and todo stay as they were until their free-form fields are written out.
