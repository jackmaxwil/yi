Tool calls are decoded against the tool's schema where the provider can do it without forcing the model's hand (Closes #995). Yi sent every tool with `"strict": false`. A Claude from 4.5 on Anthropic's API now gets each tool that converts in strict mode, up to that API's per-request caps, and OpenAI's API gets it for the tools with no optional field (edit, write, ipython); an OpenRouter or other entry opts in with `compat.strictTools`. Making every field required, as OpenAI's strict mode does, was tried on the plan-tool dogfood and refused six calls in ten against fewer than two loose, so a tool with optional fields stays loose there.
