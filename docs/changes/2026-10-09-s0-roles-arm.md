The inner runner can now run S0's model arms (#1134). `EVAL_MODEL` already picked the model for a solo arm; `EVAL_ROLES=1` appends a paragraph telling the orchestrator to spawn readers on deepseek-v4.1-flash and workers on glm-5.3-flash with an explicit `rlm.run(model=...)`, since config has no per-role model key yet. A trial row now carries `model` and `roles`, and its `costUsd` sums every session under the trial's session dir, so a child's billed spend counts toward the trial and the store's caps instead of only the root's event stream.

Three corrections found by the first paid trials. A re-run under one run-id and arm no longer re-charges earlier attempts: the cost sums only the session files that attempt wrote (`axes.scored_sessions`, shared with `axes.main`). A request that failed before returning anything no longer makes the session's cost unknown in `axes`, matching the owner's rule that it bills $0 (a grok-4.7 trial with two such xAI timeouts had no total). The runner copies the real catalog into the trial HOME, since a fresh HOME refused `openrouter/x-ai/grok-4.7` as an unknown model and scored the trial 0 in 12 s.
