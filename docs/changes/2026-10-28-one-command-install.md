Yi installs with one command: `curl -fsSL https://raw.githubusercontent.com/jackmaxwil/yi/main/scripts/install.sh | bash`. Piped into bash, `scripts/install.sh` names this machine's target, reads the release's `SHA256SUMS`, downloads the archive it lists, and installs it only when the archive's sha256 matches; a mismatch exits 1 with `nothing installed`. Run from an unpacked release it installs that tree as before. `YI_VERSION` picks a release, `YI_RELEASE_BASE` reads one from elsewhere (an `https://` or `file://` directory), and `--dry-run` and `--help` change nothing. `just publish` writes the `SHA256SUMS` it reads. The mirror now pushes each forge `v*` tag on main at its rewritten commit, checked by `scripts/mirror/sync_test.sh` in the mirror job before every push. README.md is rewritten for a new user: install, quick start, login, plugins and skills, configuration, environment, CLI, plans, subagents, programmatic use, the SDK's status and how contributions arrive.
