The console has a header row at the top of its main area (Refs #1377), always present. The workspace tabs, which used to take a row of their own only when there was more than one, sit at its left; four buttons sit at its right, copied from Claude Code: terminal `>_`, diff `±`, browser `◉` and files `▤`. They hover like every other control and click through the same hit table. Terminal opens the terminal pane in the session's directory, diff opens the review pane and files opens the `e ` file picker; browser shows a note until the browser pane lands (#1379), so the branch that builds it only replaces one arm. Each has a palette entry; diff keeps ⌘⇧R and ⌥g, files keeps ⌘O and ⌥e, terminal keeps ⌘Y and ⌥y, and browser is ⌘⇧B or ⌥w. Every row below the header sits one row lower. The buttons are worded chips (`>_ Terminal`, `± Diff`, `◉ Browser`, `▤ Files`) that fall back to the glyphs when the header is too narrow, and framed panes start one row below the header, so a pane's close mark never sits directly under a button. The header adds 32 bytes to the dist binary, 8,388,784 to 8,388,816, in two measured `Ratchet:` commits; main's answer tool landed that same 8,388,816 meanwhile, and the two together measure 8,388,832, one more `Ratchet:` commit.
