The console has a header row at the top of its main area (Closes #1377), always present. The workspace tabs, which used to take a row of their own only when there was more than one, sit at its left; four buttons sit at its right, copied from Claude Code: terminal `>_`, diff `±`, browser `◉` and files `▤`. They hover like every other control and click through the same hit table. Diff opens the review pane, files opens the `e ` file picker, and terminal and browser say which pane lands them (#1378, #1379) until those panes exist, so the branches that build them only replace one arm. Each has a palette entry; diff keeps ⌘⇧R and ⌥g, files keeps ⌘O and ⌥e, browser is ⌘⇧B or ⌥w, and terminal has no key until its pane lands (#1378), so the tape pane keeps ⌘Y and ⌥y. Every row below the header sits one row lower. The buttons are worded chips (`>_ Terminal`, `± Diff`, `◉ Browser`, `▤ Files`) that fall back to the glyphs when the header is too narrow, and framed panes start one row below the header, so a pane's close mark never sits directly under a button. The dist binary grows 32 bytes over the console-chrome change under it, 8,388,784 to 8,388,816, in two measured `Ratchet:` commits.
