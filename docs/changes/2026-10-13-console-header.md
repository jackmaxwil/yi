The console has a header row at the top of its main area (Closes #1377), always present. The workspace tabs, which used to take a row of their own only when there was more than one, sit at its left; four buttons sit at its right, copied from Claude Code: terminal `>_`, diff `±`, browser `◉` and files `▤`. They hover like every other control and click through the same hit table. Diff opens the review pane, files opens the `e ` file picker, and terminal and browser say which pane lands them (#1378, #1379) until those panes exist, so the branches that build them only replace one arm. Each has a palette entry and a key: terminal is ⌘Y or ⌥y, browser is ⌘⇧B or ⌥w, files is ⌘O or ⌘⇧E; the tape pane gives up ⌘Y and ⌥y and is reached from the palette. Every row below the header sits one row lower. The buttons are worded chips (`>_ Terminal`, `± Diff`, `◉ Browser`, `▤ Files`) that fall back to the glyphs when the header is too narrow, and framed panes start one row below the header, so a pane's close mark never sits directly under a button.
