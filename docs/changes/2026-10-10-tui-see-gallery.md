`just tui-see gallery` puts every scene and label under `target/see` on one page: each snap by label side by side, a head run's cell diff beside it, pictures inlined so the page can be published as is. `just tui-see watch <scene> [--host term]` keeps a `base` run and, on every save under the TUI crates, rebuilds, reruns the scene as `head`, diffs it and rewrites the gallery. `--video` with `--host term` keeps the whole run as `run.webp`, cropped to the Ghostty window and sized for a README. On the term host the proxy's screen emulator no longer sees kitty image payloads as text, and `wait-idle` waits for the screen to hold still a second (ticking ages aside) instead of for silent output, which the orb's frames and the sidebar's ages never gave.
