`memory.search`, `yi memory search` and `compact.search` now read a non-ASCII letter as part of its word. Before, `résumé` was indexed as `r` and `sum`, so an accented query returned notes and messages that only shared a fragment. Tokens are runs of Unicode letters, digits and `_`, lowercased with full Unicode case folding. `.`, `/` and `-` still join paths and identifiers, and the 61 English function words still drop. A history hit's snippet still centres on the first query word under the same lowercase fold. `history.search` now builds its BM25 index once for each state of the session files and reuses it until a file's length, mtime or inode changes, where before it rebuilt the index on every query. A cold session file is parsed with the lock held only for that file, so other searches no longer wait on it.
