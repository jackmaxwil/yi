`/mcp` opens an MCP page in the solo TUI, and `mcp` in the console palette opens the same page as a pane. It has a status header, a server list with state glyphs, a detail block for the selected server and a key footer. Servers come from the four config files through the new `yi mcp servers --json` verb, joined with the stored session state and the tool count from the last connect. `e` flips `mcp.enabled`, `p` probes a server, `l` runs the OAuth login, `o` opens the config file. Every action shells out to the `yi` binary, so no MCP client code runs in the TUI or the kernel. The `mcp` skill teaches it.
