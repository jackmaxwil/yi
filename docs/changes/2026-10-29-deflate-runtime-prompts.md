The runtime's fifteen embedded prompts no longer ride the binary as raw text: `crates/runtime/build.rs` deflates each one and proves the round trip, `yi-runtime::packed::inflate` inflates it once on first use inside a `LazyLock<String>`, and every accessor reads through it. The dist binary measured 8,670,176 -> 8,637,152 bytes on this host, **-33,024 bytes**, two 16 KiB `__TEXT` pages back under the measured ratchet (8,686,704 + 16,384 jitter = 8,703,088: headroom 32,912 bytes before, 65,936 after), which sits under the 9 MiB hard cap of #1354; #1401's 8 MiB arithmetic and its "next 3.8 KB fails every build" are stale against that ratchet. `miniz_oxide` was already in the graph through `yi-ai`'s catalog and `yi-orb`, so nothing joins the dependency table and no new crate is linked. The deflate step is one `pack_bytes` function in `crates/runtime/pack.rs`, which the `yi-runtime`, `yi-ai`, `yi-kernel` and `yi-tui` build scripts `include!` in place of their own deflate-and-write pairs, so the model catalogs, Python runtime and logo masks gain the round-trip proof too. The `pack` wrapper in `crates/runtime/pack_file.rs` is shared by the two file-driven builds, `yi-runtime` and `yi-ai`; it refuses input that is not UTF-8, the check `include_str!` made at compile time. Each prompt static is one `packed!("stem")` line, and the graph inflates inside its one `OnceLock`.

`every_packed_prompt_reads_as_its_own_file` holds all fourteen text prompts in one table and `the_shipped_graph_reads_as_its_own_file` checks the graph. They prove that each generated blob is a zlib stream shorter than its source, inflates to that source, and reaches its accessor unchanged. Each also requires its blob to have passed through `inflate`, so reverting an accessor to raw `include_str!` fails instead of passing with identical text.

The inputs were the production prompt static values and their source files, not a new fixture.

Both mutations used the production prompt files and their generated blobs.
