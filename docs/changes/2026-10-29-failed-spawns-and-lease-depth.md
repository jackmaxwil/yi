A spawn refused after its directory was made leaves nothing behind. The directory is created before the container placement, the tree fork and the build, and each of those can refuse; a guard removes it unless the child's record is listed, so the family names only children that ran, and a worktree child refused for a directory that is no repository leaves no `sub-*` in the parent's `children/`.

`/land` names the cause git gave it. A merge git refuses for a file the lane has uncommitted changes to starts no merge at all, and `merge --abort` then answered `fatal: There is no merge to abort (MERGE_HEAD missing)` in place of git's own message; with no `MERGE_HEAD` the landing now reports git's refusal, naming the lane to resolve it in. A conflict list stays fenced and bounded at twenty files, and past that it carries its own row: `[20 of 21 conflicted files (CONFLICT_FILES_MAX 20); git diff --name-only --diff-filter=U in <lane>]`. The landing-failed steer is bounded at 2,000 characters with the same kind of row.

A lease expires at every depth. The clock and the loop that runs expiry lived in the plan timer, which only a depth-0 session wired, so a grandchild below depth 0 whose lease was revoked had its grace served by nobody and its lane stayed orphaned. The due-time pump is now one type, `Due` in the plan timer's module: the plan timer drives it with its stuck and dispatch jobs, and `attach_runtime` spawns a second one at every depth that runs the host's lease expiry and ends once its host is dropped. `yi ask`, `yi rpc` and a solo TUI end their host before exiting: every live child is revoked and repossessed at once, the repossessions running side by side so each gets the whole shutdown grace, so its lane comes back rather than outliving the session that owns it, and the runtime still shuts down within that bound. The solo TUI and a headless drive end the host on the runtime that runs the children's turns, before it shuts down, since a turn dropped with its runtime never settles and its repossession would wait out the grace. The three exit call sites have no binary-level test: only `lanes::an_ending_host_repossesses_a_live_worktree_child_inside_its_grace` and `lanes::an_ending_host_repossesses_its_children_side_by_side`, which call the host's end directly, prove the repossession.
