The orb no longer sits over text while a reply streams. Every kitty image a frame moves (the orb, the model picker's logos, and in `yi console` the session avatars and the notebook image) is now placed inside that frame's synchronized update, with the delete of the image it replaced, so the text and the image present together. Image work on a tick that drew no text gets an update of its own (`yi_tui::term::framed`), and `yi_orb::kitty::place_nth` no longer writes the `?2026` bracket the frame already holds. In `yi console`, a chat pane now reveals streamed text at the configured `tui.pace` (default 100, as in solo; a headless run still paints on arrival), and the console loop wakes for the reveal instead of only for the orb and a 50 ms idle poll.
