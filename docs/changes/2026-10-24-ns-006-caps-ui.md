The lists, cards and rails that cut now say what they hid. The `@` picker searches every name its walk finds, up to 5,000, so typing a file's name reaches it past the first hundred the list shows; past 5,000 a `[…]` row reads `5000 of 5000+ files` and says to type the path after Esc. A finished child's answer card keeps its last 16 KiB as before and now opens with a row naming how many bytes it kept of how many, the 16 KiB cap and `alt-↓`, which opens the whole child; a console card, which has no session feed, keeps that tail when the record's 240-character preview arrives instead of swapping it for the preview. The console's Review pane counts the older files its 512-file or 4 MiB cap evicted, a turn's view counts only the files that turn lost, and an edit that brings an evicted file back no longer counts it. The rail's `+N` counts the children its 32-row cache gave up, so the 33rd running child reads `+30`, not `+29`. The test that pinned the card's silent drop is replaced. `yi mcp connect` now prints the session, its state, the server's name, its capability names and its instructions, and, when the server offers tools, the call that lists them, instead of the server's whole JSON with every schema, and a usage error prints the error and `run: yi mcp help` instead of appending the 1,521-byte help text. `--json` is unchanged, since the kernel reads `server.tools` from it.
