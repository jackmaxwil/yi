E-cli-doctor: `yi doctor` now reads the user's config leniently before the strict global load, so its lane check honors `lanes.slots` even though a malformed config remains a doctor row rather than a fatal error. The daemon socket and ledger checks honor `--socket` instead of always reading the default path, and the socket row judges that the file it would unlink is a socket before `--fix` removes it: a path that names something else is reported and left alone.

E-slow-exec-probe: exec-tool schema probes now run side by side under a pool of four, each with its own two-second deadline measured from its own start, so one slow tool cannot skip another: K bad executables cost 2s x ceil(K/4) during discovery with up to four child processes alive at once, rather than 2s each in turn, and no directory of executables can fork whole at every session start. Discovery returns both loaded tools and skipped files with reasons, and a probe that panics is named as skipped rather than dropped. `yi doctor` gained an `exec-tools` row naming every skipped executable and its timeout, nonzero exit, or invalid schema. No decisions are claimed.
