A right-click in the console opens a menu for what is under it (Closes #1251). The terminal reported the button all along and the console dropped it, so a right-click acted as a left-click and started a drag. On a chat message the menu offers Copy, which hands that one message's markdown to the clipboard over OSC 52, Copy as plain text, and Quote, which puts the message into the composer as a `> ` quote. On a pane it offers close, zoom and the two splits, and on a sidebar session open and open beside. ⌥m (or `ctrl+b m`) opens it for the focused pane or the selected session. Each row names its key, a verb that never applies to the target is absent, and one that applies but cannot run now is greyed with the reason: the last pane in a tab reads "last pane".

When a tab holds more than one pane, the focused one carries `✕` and its close key in the top-right of its title, and a click there closes it. A sibling carries a bare `✕`: the key acts on the focused pane only, and a 40-column Review header lost its counts to a mark that named it. The last pane in a tab cannot close, so it carries none. The command palette and the keys overlay carry `esc ✕` the same way.

Two defects went with it. A click while the palette or keys overlay was open fell through to the pane or session under it; an open popup now takes every press, and a press outside it or on its close mark only dismisses it. And kitty images draw above text, so the avatars, the orb and a notebook image showed through any popup over them; a popup now lifts the images it covers until it closes.
