The forge now builds and tests Yi Desktop. A fourth gate lane, `desktop`, runs the app's own format, lint, HAR and test gates on Linux for a pull request that touches `desktop/` or the Yi crates the app builds on, and says so and passes at once for one that does not. The merge queue's candidate runs it too, and the fixer reruns it like any red lane, so a bot's change to the app is compiled and tested before it lands. The app's menu-bar crate is a stub off the Mac, tests press ⌘ the way each system reports it, and eighteen tests that only a Mac can pass say why in their `ignore`. Six tests of a session's checkout ask git whether it can list worktrees with `-z` and skip, saying so, where it cannot: the forge image's git is 2.34 and the flag is from 2.36. The lane installs xkbcommon, fontconfig and one font when a Debian image lacks them, runs the app's gate scripts with the Python the repo's other gates pick, and builds the tests on a `gate` profile with optimised dependencies, without which the lane took 19 of its 20 minutes. A pull request pushed before the lane existed has no status for it and waits on nothing there; the queue's candidate, built on main, always runs it. The 211 scenes and 19 journeys still run on a Mac before a desktop change lands. #2341
