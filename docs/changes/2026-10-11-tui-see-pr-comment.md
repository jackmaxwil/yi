A pull request that can change the TUI now shows what it changed. The `tui` workflow builds the base and head binaries in the Rust image, then plays every scene under `scripts/proof/tui_see` on both on a `yi-term` runner, in real Ghostty where the scene allows (frozen scenes play headless), and upserts one comment: each changed snap's cell diff and before and after crops, uploaded as the comment's own pictures so the next push replaces them. A last job checks out the base branch and posts that comment with the token, so code the pull request wrote never holds it. The gallery page rides as the job's artifact. A local `tui_see.py ci <base> <head>` does the same and writes the comment to `target/see/comment.md` when there is no forge to post to. Each run takes a free X display, so one job can play many scenes. Console scenes start sessions with random ids, which the comment names as colour noise.
