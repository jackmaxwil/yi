# Eval ledger

One row per task-eval run. A run that is not in this table did not happen:
optimization claims cite a run-id, or they are vibes. Rows are appended, never
edited — a re-run is a new run-id. Columns are additive only; a new metric is a
new column on the right, so older rows stay readable.

Rows are written from the harness output after the run finishes, before any
commit cites them (plan §7, §8). The `Opt-Run:` commit trailer carries the same
zero-padded run-id.

## Columns

| column | meaning |
|---|---|
| run-id | zero-padded counter, shared with the `Opt-Run:` trailer |
| date | UTC date the run finished |
| suite@rev | dataset and its pinned revision, e.g. `tb21@a3f1c2d` |
| model | `provider/model` plus reasoning effort |
| config-fp | `yi_usage.config_fingerprint` — adapter version, model, mode (with `+routing{…}` under `EVAL_ROUTING`), suite |
| pass | passed / attempted tasks (A axis) |
| pass@k | attempts per task and the resulting pass@k (A axis) |
| tokens | input / cached / output (B axis; input is the uncached part, cache reads are the second number) |
| cost | self-reported USD from `usage.cost.total` (B axis) |
| wall | harness-measured wall clock per task (B axis) |
| turns | assistant steps, pier `n_agent_steps` (D/G axes) |
| peak-ctx | pier `peak_context_tokens` (F axis) |
| compactions | pier `summarization_count` (F axis) |
| notes | what was being tested; regressions; anything that makes the row unfair |
| rule-fires | labelled D54 haystack lanes (`evals/rule_fires.py`); empty until a T3 run fills it |
| persistence | `open-at-stop / intercepts(max rung) / asked-twice` — `stopped_with_open_todos`, `intercept_count` with `intercept_max_rung`, `asked_twice` (D140; docs/plans/2026-09-06-tbv4-evals/axes.md §B) |
| rigor | `gate-w/o-change / done-w/o-evidence / unsourced / seen-red` — `gate_without_change`, `done_without_check`, `count_claim`, `regression_seen_red` (axes.md §C) |
| experience | `answer-chars / offer / miss-streak / ttft-p50` — `answer_shape`, `closing_offer`, `cache_miss_streak`, median request `ttftMs` (axes.md §D) |
| timeouts | `agent/verifier/error` — trials whose agent hit its timeout (harbor `AgentTimeoutError`, run.py `timedOut`), whose verifier started and returned no result (a `VerifierTimeoutError`, or one harbor recorded under an earlier agent timeout: `verifier_result` null beside a `verifier` start time), and that ended on any other exception or a non-zero `yi ask` exit (D173) |
| partials | `Σpassed/Σtests` over the verifiers' `verifier/ctrf.json` summaries, then the mean `partial_score` of any `verifier/trace_results.json`; `-` when no verifier wrote either (D173) |
| upstreams | assistant turns per OpenRouter upstream, `name=n` most first (`Z.AI=300, DeepInfra=21`), from each turn's `upstream` diagnostic; `-` when no turn names one (D174) |
