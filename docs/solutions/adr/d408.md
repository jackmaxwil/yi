# D408: the daemon owns config writes

Status: accepted

## Decision

The daemon owns config writes: `_yi/settings` serves every leaf as a
yi_types::settings row with the file's value and `_yi/set_default` saves one at
once, refused whole by the row's rule or the strict parse; the writer moved from yi
setup into yi_runtime::settings under one lock with its own staging name

## Why

A worker holds the copy it started on, and the shared `.config.json.setup` staging
file let two writers clobber each other

## Reversible via

Route `_yi/set_default` back to a refusal and move the writer back into setup.rs
