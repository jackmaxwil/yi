# D393: provider `cursor` is compiled

Status: accepted

## Decision

Provider `cursor` is compiled: its login poll, refresh URL, CLI client-type header
and Connect client version live in the binary, and a turn calls Cursor models over
HTTP/2 (revises D191 for `cursor` alone; every other OAuth provider is still a
profile the user writes, and a profile at `~/.yi/oauth/cursor.json` still wins)

## Why

A profile cannot express the poll or the agent RPC; D191 kept identities out because
a provider's terms may forbid presenting them, and the owner accepted that risk for
Cursor: "Keep compiled, add D-row"

## Reversible via

Delete the cursor login, the Connect client and the catalog file, which restores
D191 unamended
