# D264: the console's session diff pane becomes Review, keeping ⌘G

Status: accepted

## Decision

The console's session diff pane becomes Review, keeping ⌘G: three scopes — the
lane's branch against its merge base with main (default; `_yi/branch_diff {root}`
runs `git diff`/`--numstat`/`ls-files --others` in the worker through
`lane::capture`, since the console may not spawn processes), the last turn's edits,
or the session's — with each changed file's running todo recorded when its edit
arrived, a count of files only read, the claims and landing in the header, and `l`
sending `/land <session title>`; a scope with no git base shows the session's edits

## Why

Answering what changed, for which todo, and whether it can land took a scroll
through the transcript (133 tool calls against 12 prose blocks in the owner's
screenshot session) and a trip to the forge; the owner picked "review and inbox" and
"branch vs base as default. this turn and this session are other valid options."
(#615)

## Reversible via

Keep the old session diff, drop `_yi/branch_diff` and `review.rs`
