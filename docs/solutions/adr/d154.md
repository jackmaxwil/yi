# D154: every edit and write result says whether the file still parses

Status: accepted

## Decision

Every edit and write result says whether the file still parses:
`crates/tools/src/syntax.rs` maps an extension to the language's own parse-only
check (`python3 -m py_compile`, `node --check`, `sh -n`, `ruby -c`, `php -l`, `gofmt
-e`, `rustfmt --check` for a parse, in-process `serde_json`), runs it only when the
program is on PATH under a five-second deadline, and appends `syntax: ok` or
`syntax: error line N: <message>` as the result's last line with `details.syntax`;
the edit is applied either way

## Why

Cargo 37Fs8Ha on row 0021 spent 25 of 39 turns repairing `if` and `for` headers a
range edit had eaten, discovered commands later; the verdict costs no prompt bytes
and no dependency, and silence where no checker exists is honest because the file
could not have run there either

## Reversible via

Delete `syntax.rs` and the two call sites
