# D543: a read-only shell read answers with a `[…]` row naming the dedicated tool,...

Status: accepted

## Decision

A read-only shell read answers with a `[…]` row naming the dedicated tool, not a
refusal

## Why

A refusal would take the raw bytes away from calls whose point is those bytes (a
binary probe, a format read cannot reproduce, an exit status), and the bash tool
already answers `pdftotext`/`pandoc` with a hint rather than a refusal; the row
rides the first line of the answer, so it cannot be missed the way a doctrine line
was

## Reversible via

Reversible via deleting the `shell_read_hint` call in `BashTool::execute`
