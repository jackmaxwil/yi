# D185: the prompt loses what nothing calls

Status: accepted

## Decision

The prompt loses what nothing calls: `orchestrate.md` and its attach go, so the
prefilter and the four trajectory signals only record (`route`, and
`orchestrate_attached` once per session under its old key) and send no reminder;
`Effect::DetachFragment`, which nothing constructed, `PromptState::detach` behind
it, `prefilter` and the unread `pub use` of `ext::{Features, Route, features,
prefilter}` go; doctrine drops Look before you write, Planning, the lane half of Git
and lanes (its git-safety rules stay as a short Git section: git runs through
`bash`, which is called), Working model (with its readers clause in Method's Ground
step) and Context, and the Todos sentence that forbade a turn whose only call is a
todo op; identity names `get_context` and `plan` in one line each and drops the RLM
bullet and its example; the request budget is locked at the shrink, system 28,320 ->
22,023 bytes (revises D166, D138)

## Why

On row 0028 the fragment attached in 12 of 21 sessions and rode every later turn at
8,131 characters, and no session called `rlm`, `plan` or `get_context`, as none did
in row 0027's 1,223 turns; with the fragment, the text on those tools was 41% of the
system prompt's characters; the todo sentence contradicted the stop intercept, which
asks for a state move and accepts one alone, and 132 of 280 tool turns broke it
anyway (the 2026-09-10 harness audit, T4, T7, M2, A7)

## Reversible via

Restore `orchestrate.md`, the attach and the reminder in `Orchestrate::escalate`,
and doctrine's and identity's sections from 0.226.0; the request budget returns with
them
