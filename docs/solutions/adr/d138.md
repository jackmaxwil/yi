# D138: the prompt is comprehensive and its ceiling is the ratchet

Status: accepted

## Decision

The prompt is comprehensive and its ceiling is the ratchet: identity.md opens with a
Reporting block, names every registered tool including `todo`, `get_context` and
`plan`, and shapes the answer by request class (a small change, a change across
files, a large change, a diagnosis, an assessment, a question) instead of a fixed
two paragraphs; doctrine.md grows from 89 to about 330 lines and carries Persistence
(the user never asks twice; a turn does not end with work the model could still do),
Todos (every state and the op that moves it, stated so the model always can and
should block, drop or finish an item itself), Request classes (answer, diagnose,
assess, change, each with its evidence and stopping point), Method (eight phases
with exit conditions), Evidence (count hygiene, truncation pointers, the chain-stop
rule, the sandbox), Testing (see it red first, external ground truth, race
attribution), Debugging, Planning, Tools and output, Git and lanes, Delegation,
Context, and scopes Done is a measurement to a change the model made; the mode
fragments name the sandbox posture and `yi trust`. D26's 8 KB preamble ceiling is
revised: the prefix is cached and one path, so the ceiling is
`check_request_budget.py`'s shrink-only ratchet, grown by one `--update` in its own
commit per stage of docs/archive/plans/2026-09-06-prompt-surface.md

## Why

The provoking session: 89 lines of doctrine said "run the relevant check" with no
scope, the Voice fixed every answer at two paragraphs, and nothing told the model
what an assessment is, what the sandbox denies, what a `[full output:]` pointer
means or that the repository's records outrank a re-measurement; a rule the model
has not read is the expensive one, and a cached kilobyte costs less than one wasted
call. One prompt for every model: a rule a cheap model needs and a frontier model
does not is written once, exactly, and costs the frontier model one cached read (the
two-register design was weighed and rejected the same day)

## Reversible via

Restore the 0.164.0 fragments; the ratchet accepts a shrink without ceremony
