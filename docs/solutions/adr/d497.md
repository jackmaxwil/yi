# D497: the skill classifier points at a skill on its own once `models.classifier`...

Status: accepted

## Decision

The skill classifier points at a skill on its own once `models.classifier` names a
checkpoint: an unset `classifier.threshold` is 0.9, not shadow mode (revises D297's
record-only default)

## Why

The owner: "once laya plugin is enabled, it should default be on. it should not
default to watch only"; on the owner's Mac 14 answered decisions in two weeks
reached confidence up to 0.9998 and none fired, because no threshold was set

## Reversible via

Read an unset threshold as no threshold again in `classifier::threshold` and make
`Sidecar::threshold` an `Option<f64>`
