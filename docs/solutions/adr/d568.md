# D568: a head whose own latest read was clean is read again when a later round read...

Status: accepted

## Decision

A head whose own latest read was clean is read again when a later round read another
commit, while a blocked or retry-capped head stays refused (revises D565)

## Why

#1852 sat forever between "round 2 read this head" and "round 7 reviewed b6c0477c,
not the head", so neither the reviewer nor the queue moved it

## Reversible via

Delete the stale-latest-round guard at the end of `skip_reason`
