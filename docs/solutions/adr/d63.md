# D63: syntax highlighting is a hand-rolled scanner, not syntect

Status: accepted

## Decision

Syntax highlighting is a hand-rolled five-language scanner in
`yi-tui::highlight` — Rust, Python, shell, JSON and TypeScript/JS — not
`syntect`, and not behind a cargo feature. §8.14's earlier line, "`syntect` with
a trimmed syntax set is a later `highlight` feature", is revised by this row.

## Rationale

The dependency was measured before it was rejected, not assumed away. A probe
binary carrying syntect 5.3 with `regex-fancy` and the default 75-syntax set came
to 681,984 bytes against a 286,208-byte baseline built beside it: +0.38 MiB
against the 0.29 MiB left under the 6 MiB dist budget, plus 39 transitive crates
against a 167 ceiling, on a crate §13.5 bans by name. The numbers are in
docs/size-ledger.md. That is not a close call the budget could absorb; it is over
the line on both axes at once.

A trimmed syntax dump would have fit the bytes. It costs vendored
`.sublime-syntax` blobs in the repository and a `yaml-load` build step to turn
them into a binary dump, which trades a size overrun for a build-time dependency
and a set of opaque committed artifacts. Neither is obviously better, and the
thing being bought is generality Yi does not use.

The scanner covers exactly the languages Yi's own surfaces show, and cost 33 KB
for this phase and the two before it. The scope that keeps it small is the scope
that keeps it honest: scanning is per line, so a string or block comment crossing
a line boundary is not tracked, because that state costs a parser and buys one
mis-coloured row. A line over 4 KiB renders plain. There is no token cache,
because the cost OMP's LRU-256 exists to amortise is an FFI hop and a regex
engine, and this is a char walk. An unknown language name renders plain rather
than guessing.

The cargo feature goes with the dependency. A feature exists to make a dependency
optional, and there is no dependency — a feature gating nothing gates nothing,
and would only add a build configuration nobody exercises. The policy borrowed
from codex is kept exactly: foreground and bold, never a background, never italic
or underline. A background would fight the U37 tint the row renders inside, and
the other two attributes are what terminals render least consistently.

## Reversal path

Delete the module and the four call sites; every surface renders the plain text
it rendered before.
