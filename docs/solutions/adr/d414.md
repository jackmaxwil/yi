# D414: grep takes history

Status: accepted

## Decision

Grep takes history:// roots (self, parent, a child, repo) and matches every line,
tool output included, through the resolver's own alias and wall checks;
compact.search keeps its messages-only index

## Why

A past command's output was findable only by a ranked search that never indexes it,
or by reading whole transcripts, and the paired GLM 5.3 flash run needed 11 to 16
calls for one line

## Reversible via

Drop the grep arm in fetch::route_urls and the path description line
