# D572: the kernel package ships no harness store

Status: accepted

## Decision

The kernel package ships no harness store: rlm.harness, rlm.get_harness_state and
the Harness* types are deleted with the harness.save_global host request and the
RLM_GLOBAL_HARNESS_STATE_DIR and RLM_GLOBAL_HARNESS_HOST env (retires D270)

## Why

No prompt, skill or Yi code reads the store, and every line of it rebuilt the venv
when it changed

## Reversible via

Restore python/yi_runtime/src/rlm/harness.py, its re-exports and
kernel_state::register_harness_save from git
