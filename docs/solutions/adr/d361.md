# D361: user text never seeds the todo list

Status: accepted

## Decision

User text never seeds the todo list: the agent alone writes todos, with the
`first_list` backstop and the hidden planning hint kept and the hint now saying
nothing was written for it and a pasted document is context; a list line needs one
to three digits and a space after its marker (revises D148)

## Why

The owner: "Never from my text", and that the seed did not slice a message correctly
and was low quality and noisy; pasted README text and numeric output such as `1.234
ms` filled the todo block before the model replied

## Reversible via

Restore `seed` and `seeded_text` from D148
