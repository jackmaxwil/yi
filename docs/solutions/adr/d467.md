# D467: a root child spawned where it cannot spawn (can_delegate = depth + 1 <...

Status: accepted

## Decision

A root child spawned where it cannot spawn (can_delegate = depth + 1 < max_depth is
false) is never registered for the orchestrate protocol, and a fork=all child gets
no exemption

## Why

It cannot delegate (the depth refusal in SubagentHost::spawn stops it), so 11,491
request bytes on a triggered prompt are dead weight, and a fork's request prefix is
not its parent's anyway: measured, the fork's tool table is 15,181 B against the
parent's 17,673 B

## Reversible via

Pass can_delegate: true for every child in child_factory
