# D601: reclaim keeps a read or grep result past the age floor while every...

Status: accepted

## Decision

Reclaim keeps a read or grep result past the age floor while every `[path#TAG]` it
printed matches the file on disk and the last reply used under
`reclaim.keep_below_pct` (30) of the window (amends D597)

## Why

Ten Sonnet 5.5 children reread a path they had already read 518 times and repeated
197 exact calls because results aged out at five requests while under 10% of the
window was used; 396 of the 404 rereads past the floor were of a file whose tag had
not changed

## Reversible via

Reversible via `reclaim.keep_below_pct = 0`, which restores the age-floor-only rule
