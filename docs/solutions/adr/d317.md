# D317: a child's transcript lives inside its parent

Status: accepted

## Decision

A child's transcript lives inside its parent: a root with a transcript puts each
child's directory at `<its file without .jsonl>/children/sub-<8 hex>/` (read at
spawn, since the file is attached after the host is built and `/new` swaps it), a
child puts its own at `<its dir>/children/sub-<8 hex>/`, and a root with no
transcript keeps `rlm-<pid>/sub-<8 hex>/`; the directory keeps the child id as its
name, not the child's name, which may hold `/` or recur after a reap; a parent file
that does not end in `.jsonl` keeps `parent_session_dir`; the child's v4 header
names its parent (`parentSessionId`); the parent's log carries a `custom{child}`
trail (`ChildTrail`): `spawned` with the name, id, session id, the file's path
relative to the parent file's directory and the brief's SHA-256, and `ended` with
the exit, error and cumulative tokens, once per run (an idle service's turn writes
none), in the log that recorded the spawn even after `/new` swaps the root's;
`history://<child>` falls back to the newest `spawned` line matching the name, the
id or a `/name` suffix, as the live roster matches, so a trail outlives the roster
and a restart; a fork copies the lines and so points at the original's children;
deleting a session deletes the directory beside its file, before the file, so a
failed delete can be retried; a child inherits its parent's family board path
instead of deriving it from its own directory

## Why

A child's file sat at `rlm-<pid>/sub-<8 hex>/`, keyed by the process rather than the
session, so a `--continue` run started a new directory; neither file named the other
(no `parentSessionId` on `rlm-12814/sub-fbef2e42`), and a reaped child was found
again only through an in-memory map a restart loses; the owner: "a full file in a
dedicated directory, not cluttering the parents directory", a "pointer to child
transcription location on disk", and "children should stay in their parents" (#879)

## Reversible via

Drop `subagent/trail.rs` and the `children_dir` call, pass `None` as the parent id,
and remove the trail lookup from `SessionTranscripts::open`; old trail lines stay
readable
