# D492: A resumed session rebuilds its base prompt slots from the current build and...

Status: accepted

## Decision

A resumed session rebuilds its base prompt slots from the current build and re-
attaches its late ones; within one process the prompt stays frozen (amends D310)

## Why

The saved snapshot overwrote the current mode, identity and doctrine, and every
session file carried the whole prompt

## Reversible via

Reversible via restoring the snapshot wholesale in Host::start
