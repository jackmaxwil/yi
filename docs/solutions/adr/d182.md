# D182: the artifact and closure gates are deleted, and a config that still names...

Status: accepted (reverses D162; strikes D168's cut-turn steer clause)

## Decision

The artifact and closure gates are deleted, and a config that still names them
loads: the todo coupling no longer reads the prompt's product paths or the
workspace's checker, sends no `None of … exists yet` steer and refuses no clean stop
for a missing path or an unrun check (`gate_redrive`, `artifact_candidates`,
`find_checker`, `track_turn`, the three texts, `Options.cwd` and `Options.gates` and
twelve `Cycle` fields go; D158's figure re-drive stays, and a cut turn counts toward
nothing); `--no-gates` goes and `UserConfig` refuses a `gates` key, so
`yi_types::config::parse` runs `migrate` over the raw file first, the tree's first
config migration: a top-level `gates` is dropped as `ConfigMigration::RemovedGates`
and `yi` names each drop once on stderr; `extract.py` keeps `artifact_steer`,
`artifact_refused`, `closure_refused` and `gate_waived`, reading 0, as D163 kept
`length_forced`; every crate carries a size budget at its size and `just ratchet`
runs `check_growth.py --update`, which absorbs growth only across a version bump,
and `just land` prices the row from main's `src_loc.json` before it ratchets
(reverses D162; strikes D168's cut-turn steer clause)

## Why

On row 0028 the artifact gate refused nine stops and waived nine with no file
written, since the fixtures' `/app` paths are read-only inputs outside the eval's
cwd, and in harbor it read `/app/Bq/kg` out of the foodstuff prompt as a file to
write; the closure gate asked for `python3 tests/test_calc.py`, which cannot import
the package under test, counted a `cat` of the file as its run, and accepted six red
stops of six; turns rose from 121 on row 0022 to 321 on row 0028 for the same 21/21
(the 2026-09-10 harness audit, G2, G4, G5); the independent recheck that would have
kept `artifact_candidates` was dropped; the size ratchet covered two of fifteen
crates and `src_loc.json` sat at 0.142.0, so every growth memo restated one
cumulative number (A4, A5)

## Reversible via

Restore the gates, `Options.cwd`, the `Gates` config and `--no-gates` from 0.215.0
and delete `ConfigMigration::RemovedGates`; the crate budgets and the growth refresh
stand alone
