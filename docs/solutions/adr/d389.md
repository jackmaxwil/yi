# D389: `ask_user` is registered only in a child, whose parent answers it, and with...

Status: accepted

## Decision

`ask_user` is registered only in a child, whose parent answers it, and with auto-
review on, where it escalates a denial; a root session with no reviewer asks in its
reply, and the first open-todos stop now tells it to block the item on user and ask
in the same message, which only the second did before (one in, one out for
`annotate`; YI_DESIGN §1.2)

## Why

The owner chose "Demote ask_user" for annotations' slot; it had 2 calls in 795 root
sessions, and the tool table stays byte-constant per session either way

## Reversible via

Push `AskUserTool::new(None)` in `wire_role` for every session again
