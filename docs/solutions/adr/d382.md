# D382: the tool table stays byte-constant for a session and defers documentation,...

Status: accepted

## Decision

The tool table stays byte-constant for a session and defers documentation, never a
tool: `edit`, `plan`, `todo` and `ask_user` carry a short summary, their parameter
schema (`plan` without field prose below the top level) and
`read("yi://tools/<name>")`, which serves the whole guide; `read`, `grep`, `bash`,
`write`, `get_context` and `ipython` stay whole; an edit refusal names the address;
there is no dispatcher tool, and provider-native deferral (`defer_loading`,
`tool_search`) is only ever an adapter

## Why

The owner: "Non important tools get a pointer to read the full definition"; the tool
table fell from 24,754 to 16,423 bytes of a 53,369-byte prefix, and a changed tools
array invalidates the whole Anthropic cache, while a guide read lands after the
prefix

## Reversible via

Restore each description from its guide constant and drop the `yi` arm of the
resolver
