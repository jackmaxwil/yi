# D306: the system prompt is constant for a conversation

Status: accepted

## Decision

The system prompt is constant for a conversation: the first request's rendering is
the bytes every later request sends (`ext::Host::system_prompt` holds it in a
`OnceCell`; `session/run.rs` `run_once` refuses a change in debug builds), and a
fragment attached after it (orchestrate's four trajectory signals, a language pack
armed by a write, a permission-mode switch, any `Host::attach`) rides the transcript
once as a persisted `fragment` custom entry that `convert_to_llm` renders as
`<yi_internal_context source="fragment">`, delivered through the host's one `Notice`
hook (now `Fn(AgentMessage)`, the reminder line's hook too) into the steer queue, so
a running turn presents it at its next message boundary and an idle session with its
next turn; the slot still lands in the `ext_state` snapshot a resume restores, so a
resumed process carries the fragment in its prompt from its first request and the
extension's idempotent re-attach delivers nothing; session-start fragments
(identity, doctrine, mode, user system, schema, project files, skills catalog, packs
by marker, grid, memory, the auto-reviewer's) assemble into the prompt as before; a
late `AttachExternal` has no delivery and is refused in debug builds

## Why

#744: a mid-session orchestrate attach, language pack or permission-mode change
rewrote the trusted system block through `AttachFragment`, which invalidated every
cache tier and rewrote the whole history at 1.25x; all 14 system-prompt changes in
the 85 recorded sessions were this, and both main Opus sessions had one, at requests
7 and 12 (`cache-algorithm-2026-09-28.md` §4, §7 invariant 3, §8 C2). Ceilings: the
late fragment leaves the context at the compaction that summarizes its window, as
every internal message does, and nothing re-delivers it; a late `DetachFragment` has
no producer and changes only the resume snapshot; the debug assertion panics the
turn's task, which nextest reports as a timeout with the message on stderr

## Reversible via

Drop `frozen` from `ext::Host` and render `state.assemble()` per call, return
`Notice` to `Fn(&str)`, delete `fragment_message` and the `fragment` arm of
`internal_source_of_custom`, and drop `system_prompt_sent` from `Shared`
