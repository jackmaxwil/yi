# D564: Every direct feature-ledger edit is refused, whenever it was committed...

Status: accepted

## Decision

Every direct feature-ledger edit is refused, whenever it was committed (extends
D524)

## Why

31 of the 33 unmerged jack branches editing ARCHITECTURE.md changed a feature-ledger
row, and the pre-2026-11-02 exemption still let those branches conflict on recorder-
owned rows

## Reversible via

Revert the whole change: restore the commit-date exemption in
scripts/guardrails/check_changes.py together with the old-edit refusal in
scripts/record_changes.py's ledger selfcheck, which expects that edit to be refused
