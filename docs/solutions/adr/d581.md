# D581: A message stops at its first failed write or command, judged by shown_failed...

Status: accepted

## Decision

A message stops at its first failed write or command, judged by shown_failed so a
non-zero exit counts, and every later call in it is answered not_run naming that
call; an interrupt still answers aborted (amends YI_DESIGN §4.2, which ran every
call)

## Why

An edit refused on a stale tag still ran its test, and the next request read a
result for code that never changed, so batching an edit with its check was unsafe

## Reversible via

Stop consulting AgentTool::gates_message in crates/loop/src/batch.rs
