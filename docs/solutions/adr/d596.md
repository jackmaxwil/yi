# D596: a review round runs on any model family, so `just pr review` no longer...

Status: accepted

## Decision

A review round runs on any model family, so `just pr review` no longer refuses the
authors' family (`anthropic`) and `AVOID_FAMILIES` and `family()` are deleted

## Why

The owner directed that review models should not block on being from the same
family, and the refusal stopped a round from running in a session whose own model is
Anthropic

## Reversible via

Restore `AVOID_FAMILIES = ("anthropic",)`, `family()` and the refusal at the top of
`cmd_review`
