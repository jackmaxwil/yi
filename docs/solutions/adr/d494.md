# D494: The 1,200-line ceiling counts production lines and a file past 1,000 may not...

Status: accepted

## Decision

The 1,200-line ceiling counts production lines and a file past 1,000 may not grow
until it is split at a seam

## Why

The ceiling counted inline tests, so modules packed to the cap (36 files within 100
lines of it) instead of splitting

## Reversible via

Revert the PR; the whole-file count returns
