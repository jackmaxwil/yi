# D559: a route's moving tail mark is suspended for an hour after four consecutive...

Status: accepted

## Decision

A route's moving tail mark is suspended for an hour after four consecutive
unexplained requests that wrote and read nothing back, and a 400 naming a cache
field is retried once with only the encoder's cache fields stripped

## Why

The session ledger already shows both failures, so no model, probe, stored state or
outbound routing change is needed

## Reversible via

Remove the tail escalation in `cache_miss::MissTracker::escalate` and the strip
branch in `request::send_stripping_cache`
