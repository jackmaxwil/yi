# D35: Phase 2b scope trims (registers, per-segment decisions, minimal holds)

Status: accepted

## Decision

Three trims to the 2b batch: (1) hashline clipboard registers are deferred — instrumentation hooks land, the feature returns when session stats show move-heavy editing; (2) D26 compound-command permission decisions ship v1 as whole-command rules plus `ParseOutcome::Unparsed` as a distinct decision input — per-segment decisions wait for a real prompt-fatigue case; (3) M5 holds land as the type and a `decide()` input with User source only.

## Rationale

Registers are unproven token economics paying real parser complexity. Per-segment decisions need a shell parser, in tension with M10's "no parsing cleverness" rule — and the codex post-mortem lesson was that unparseable commands must never be re-keyed onto `bash`, which the v1 scope preserves. Holds' consumer (the advisor) is phase 5; building TTL and headless-degrade plumbing now is scaffolding ahead of the gate.

## Reversal path

Each restores from its cited A.3/A.4 span; `decide()`'s signature already carries holds, so widening is additive.
