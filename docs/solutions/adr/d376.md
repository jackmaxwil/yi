# D376: `spend.alertUsd` shows one `spend_alert` notice per multiple of billed...

Status: accepted

## Decision

`spend.alertUsd` shows one `spend_alert` notice per multiple of billed dollars
crossed, counting the session's own replies and each child's billed spend, which
`ChildUpdate` now carries as an optional `cost`; it warns and never stops work,
beside the unchanged `spend.alertTokens`

## Why

One Opus session cost $87.34 of the $144.06 billed across 1,096 sessions, and a
token budget cannot say dollars when a cached token costs a twentieth of an uncached
one; the owner chose "Warn only, per session and per day"

## Reversible via

Drop the `alertUsd` key and the `Measure::Usd` arm; the `cost` field stays, additive
and unread
