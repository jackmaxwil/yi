# D114: D54 matches results, paths, and skill pointers

Status: accepted

## Decision

The D54 matcher stays one engine. It gains `scope: result` and `scope: error`
(post-tool, remind-only), `paths:` as a glob AND against the call's `path`
field (`yi-permission::glob_matches`), `after: N` on an evidence hash, a latch
keyed on `(rule, evidence)` so the same needle on a new path can still speak,
and optional SKILL.md `trigger:` that compiles to `Relevant: skill://name`
(at most two pointers per scan, suppressed after a `read` of that skill).
Gate remains pre-spawn. Regex and stream abort stay out.

## Why

The 0.139.0 cassette scored current recall at 0 on rustc codes that exist only
in a tool result. Skill `trigger:` is optional frontmatter the author already
wrote; a pointer the model fetches is cheaper than injecting the file.
`yi-permission::glob_matches` is the path compiler already paid for.

## Reversible via

Drop `check_result`, `discover_armed`, and the new frontmatter keys.
