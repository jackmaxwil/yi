# D612: Admit children and lanes by host headroom, never by a fixed count

Status: accepted

## Decision

Admit children and lanes by host headroom, never by a fixed count

## Why

A count of 8 refused work a roomy host could run and let a loaded one thrash

## Reversible via

Reversible via family.max_children, family.cap and plan.width_max levers set above 0
