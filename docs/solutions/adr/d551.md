# D551: a reply opens with its status

Status: accepted

## Decision

A reply opens with its status: the `answer` tool's `summary` heads the reply the
user reads, written as `Problem:`, `Ready:` or `Done:` and one plain sentence, a
summary alone is a whole reply, a plain-text reply already on screen stands as
written and a `Problem:` or `Ready:` summary that could not head it is refused, so
it comes back over new text; the todo gate sends a `Done:` answer back while an item
is blocked until its send-back ladder tops out, and a plain-text `Done` once; text
that parses whole as JSON stays bare, and no line is added that would change the
JSON a structured reader parses out of the reply; the identity prompt replaces
D523's Voice with a stance (do the work, stop only at what cannot be undone or
speaks for the user, hand over one action that cannot go wrong), facts kept apart
from marked opinions, and register matching (the user's language, length and tone,
swearing only after the user does, plain words with no code, file names, commands or
jargon unless the user writes them, the long version when asked for depth), and a
reply to another agent counts as saved work; D523's two-short-paragraphs rule goes
(amends D523); doctrine lets a diagnosis end in its fix and keeps an error's exact
text for saved work or a user who asks, and the repository's done bar, guardrails
rule and refute skill say the same, while commits still wait for the user's word

## Why

The owner: "I dont want to ever be handed things to do", "I want Yi to have opinions
about things but clearly delineate their opinion from absolute ground truth", "In
general, try to match the user" and "I don't want to look at files, code, syntax,
jargon"; every answer already carried a required `summary` that no screen showed; a
`--here` session has no lane, so committing unasked stays off

## Reversible via

Restore identity.md, the doctrine and orchestrate sentences, the three ruler lines
and prose.py's rule and stems, return `headed` to the bare text, refuse a summary-
only answer again and drop the `Done:` check; no schema, wire shape or config key
moves
