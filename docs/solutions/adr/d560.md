# D560: Run test processes under private TMPDIRs, removed by a wrapper

Status: accepted

## Decision

Run test processes under private TMPDIRs, removed by a wrapper

## Why

Tests that build dirs under temp_dir() by hand, and runs nextest kills before Drop,
left ~96,000 entries (20 GiB) in the user TMPDIR

## Reversible via

Delete the wrapper-scripts block in .config/nextest.toml and the wrapper calls in
justfile
