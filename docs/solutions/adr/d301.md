# D301: a bare rlm.run is a question-child

Status: accepted

## Decision

A worker spawn that names no `role` is a reader: `SubagentHost::admit` inserts `role="reader"`
before the parse. A plan delegation (`kwargs_of`) and a juror (`plan/judge.rs`) name
`role="root"`, a service stays root, and the prompt and README examples name `role="root"` where
they mean a writer

## Why

The owner chose "A question-child (Recommended)" for a bare call on 2026-09-28. D300 shipped the
reader as an opt-in first, so this flip, which touches every worker spawn in the tests and the
prompts, lands on its own (#822)

## Reversible via

Drop the insert in `admit`; the explicit `role="root"` arguments are harmless either way
