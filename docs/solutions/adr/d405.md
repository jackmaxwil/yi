# D405: a right-click in the console opens a menu built from the target under the...

Status: accepted

## Decision

A right-click in the console opens a menu built from the target under the click
(message, pane, sidebar session) and a table of verbs per target kind, each an
existing action; a verb that never applies to the kind is absent and one blocked by
state is greyed with its reason; an open popup takes every press

## Why

The button was dropped, so a right-click focused a pane and began a drag, and verbs
reached only by keys stayed undiscoverable

## Reversible via

Delete menu.rs and app/menu.rs, the RightDown and Moved mouse kinds, and the Menu
mode
