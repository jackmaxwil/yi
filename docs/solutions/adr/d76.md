# D76: long-horizon decomposition is a deterministic protocol

Status: accepted

## Decision

Five mechanisms, none of them a prompt: check-first admission (a task enters Running only
with an executable check); lazy splitting (attempt whole first, split after A consecutive
reds, the model proposing `SubtaskSpec` while deterministic code validates collect-all and
lowers the topology); key-scoped typed transport (`context_keys`/`check` kwargs on
`rlm.run`, a mandatory `discoveries` field on `ChildResult`, malformed results fatal);
derived criticality with a drain gate (a discovery is HIGH iff the runtime re-runs the named
ancestor check and confirms the violation, and goal completion is refused while one stands);
and counter-driven escalation through the `LADDER` const, whose thresholds are stationary and
read no spend field.

## Rationale

ADaPT: as-needed splitting beats always-decompose by up to +28 pts. RSTD: static upfront
splits cost up to +80.5 % retry tokens over monolithic. Planetarium: ~75 % of unvalidated LLM
formalizations are subtly wrong — so upfront DAG compilation is inverted, not adopted. MAST:
~42 % of multi-agent failures are specification failures, hence typed transport. SKILL.state
scores 0.94 against 0.18 at equal budget with reasoning discarded after a validated patch,
and its own limitation — an uncommitted observation is gone — makes discoveries a schema
field rather than a scratchpad. Kawase: stationary abandon thresholds convert quadratic
sunk-cost loss to linear. The model proposes, code disposes.

## Reversal path

Every piece is additive on plan, goal and subagent. Dropping the split validator returns
`rlm.run` to its prior kwarg set (unknown kwargs were already rejected by name), the drain
gate is one refusal branch in goal completion, the ladder is one const table, and the
yi-types shapes survive as unknown data.
