# D584: the autofixer pushes what its fixer wrote with no gate that guesses the...

Status: accepted

## Decision

The autofixer pushes what its fixer wrote with no gate that guesses the author's
intent from the PR's own history: `scripts/fixer_guard.py` is cut, and
`scripts/guardrails/check_intent.py` (a recorded `cut:` or `keep:` line, read on
every branch by any author) is the only gate on a deliberate cut

## Why

The guard read "a commit deleted five or more lines an earlier commit of the same PR
added" as a reversal, so on a young or imported PR every review-driven dedupe
tripped it; on PR 2130 the fixer spent $3.38 (Opus 5.5, 63 turns) on findings that
asked for exactly those edits and nothing was pushed, because the check ran only
after the spend and a finding was deliberately no exemption, so removing
`autofix:hold` retried into the same refusal

## Reversible via

Restore `scripts/fixer_guard.py` and its two incident logs from the commit before
this one, put back the `scan` call before `push_head` and the `reversed` verdict in
`scripts/pr_autofix.py`, and the selfcheck line in
`scripts/guardrails/check_guardrails.sh`
