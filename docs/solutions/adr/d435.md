# D435: a lane session's status row names the repo alone

Status: accepted

## Decision

A lane session's status row names the repo alone: `LaneHandle::row` stays the one
builder and `_yi/workdir` still carries its text, but the `⎇ lane <slot>` suffix is
gone (amends D208)

## Why

The owner asked for no "⎇ lane 0" on the console status row (#1371); the slot number
is pool bookkeeping nobody acts on, and the row already says which tree by its repo

## Reversible via

Restore `format!("{repo} ⎇ lane {}", lane.slot())` in `LaneHandle::row`
