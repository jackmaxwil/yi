# D567: `yi setup` asks two numbered menus, takes the key of the provider picked,...

Status: accepted

## Decision

`yi setup` asks two numbered menus, takes the key of the provider picked, and always
records that it ran, amending D300

## Why

The first-run flow asked free text, ended with no config when nothing was chosen so
every launch asked again, saved a model whose key it never took, and a dogfood as a
first-time user found the jargon and dead ends; the classifier question is dropped
because `models.classifier` is already a config key

## Reversible via

Restore the free-text prompts, classifier_step and the no-write finish in
crates/cli/src/setup.rs
