# D436: the console chrome takes its colour from the session, not from one accent

Status: accepted

## Decision

The console chrome takes its colour from the session, not from one accent: a pane's
title chip, border, scroll thumb and solo-chat title wear that session's own hue
(`App::accent_of`), a pane with no session wears `muted`, the command palette, menus
and settings tabs go neutral with an amber prompt, and accent blue stays on links,
the markdown H1 rule, the sidebar and the hint bar's palette key (amends D200)

## Why

The owner asked for the pane title, tab and palette to stop using blue, "blue is
overused", and chose "Each session's own colour"; a colour now says which session a
pane shows

## Reversible via

Restore `theme.accent_style()` at the chrome sites `render_borders`,
`render_thumbs`, `tab_bar`, `palette::render_navigator` and `menu::render`
