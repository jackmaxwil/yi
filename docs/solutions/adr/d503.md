# D503: A memory journal append reads only its last record and takes the full replay...

Status: accepted

## Decision

A memory journal append reads only its last record and takes the full replay when
the file does not end in one whole record; a broken chain is named by yi memory
rebuild, which replays it whole (amends D277 'replay per append')

## Why

Every memory.read appended a record after replaying and re-verifying the whole
chain, so a read cost grew with every read ever made

## Reversible via

Restore append's replay
