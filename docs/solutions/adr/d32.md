# D32: Pi session compat targets the v4 mutation log

Status: accepted

## Decision

Pi session compat targets the v4 mutation log: yi-types models header + every entry/record/lane/fact shape, fixture-locked byte-identical (fixtures generated by Pi's own storage code); S7's operation-log cut narrows to "Yi maintains none" — records are read, preserved, re-emitted, never runtime-maintained

## Rationale

Pi moved v3→v4 under the design (verified 2026-08-23); byte-compat against a stale format is meaningless

## Reversal path
