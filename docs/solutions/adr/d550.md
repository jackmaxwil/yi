# D550: `annotate` and `get_context` join the deferred-guide set

Status: accepted

## Decision

`annotate` and `get_context` join the deferred-guide set

## Why

Their descriptions are read on every turn and the tool table is byte-constant for a
session, so the bytes move to `read("yi://tools/<name>")` as `edit`, `answer`,
`plan`, `todo` and `ask_user` already do

## Reversible via

Restore each description from its guide constant and drop the two `TOOL_GUIDES` rows
