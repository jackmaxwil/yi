# D417: `YI_FIXED_IDS`, read by `IdGenerator

Status: accepted

## Decision

`YI_FIXED_IDS`, read by `IdGenerator::new`, makes the session ids a process mints a
process-wide counter (`01a00000-0000-7000-8000-<n>`, from 1) instead of random; only
the TUI scene runner sets it

## Why

The id hashes to a console session's avatar and badge colours, so every console snap
differed in a few cells between any two runs and the PR comment had to say to read
past them

## Reversible via

Delete `FIXED_IDS_VAR` and the `fixed` field; `IdGenerator::new` mints random ids
again
