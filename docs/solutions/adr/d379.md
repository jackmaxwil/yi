# D379: `yi stats --since <span> --by model, upstream or day` with `--top N` folds...

Status: accepted

## Decision

`yi stats --since <span> --by model, upstream or day` with `--top N` folds every
session file under the sessions directory (children and legacy `rlm-*/sub-*` files
included) once per response id, from each assistant reply's `usage.cost.total`; the
parent's `child_usage_attributed` records are never read

## Why

A child's replies sit in its own file, so reading the parent's attribution beside
them counts the child twice, and the reply's billed total is the provider's figure
on OpenRouter where the catalog is not

## Reversible via

Drop `rollup::scan` and the `--since`, `--by` and `--top` flags, which only `stats`
accepts and which refuse a session id; `yi stats [id]` is unchanged
