# D156: the kernel ships with the binary

Status: accepted

## Decision

The kernel ships with the binary: `crates/kernel/build.rs` deflates
`python/yi_runtime` and `python/skills` into the crate, `resolve_python_root` walks
up from the exe, then `~/.yi/python` when its stamp matches, then unpacks the embed
there atomically, and only with HOME unset or a failed unpack falls to the compile-
time path; `yi doctor` gains the `python-runtime` row and `--fix` re-unpacks

## Why

Every `ipython` call inside a harbor trial on rows 0018 and 0021 failed with the
build machine's checkout path, so D149 pointed the model at a dead tool (issue
#278); a dist binary installed away from the repository had the same defect for any
user

## Reversible via

Delete the build script and the embed; `resolve_python_root` returns to its three
steps
