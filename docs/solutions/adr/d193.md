# D193: the second search-shaped bash timeout in a row names the streak and the recovery

Status: accepted

## Decision

The second search-shaped bash timeout in a row names the streak and the recovery:
`BashTool` counts consecutive timed-out calls whose `command_category` is `search`
or `list_files` (any other call starts the row over), and from the second the result
adds `[N searches in a row timed out; the grep tool walks and pages with no wall-
clock kill, or bound the command: name the directory, add -maxdepth/--max-depth N,
pipe through head]`

## Why

Layout-config-recreation spent 88% of its time in timed-out searches, each result
naming only the generic timeout_secs recovery (the 2026-09-11 v4 sweep); the first
timeout is noise, the second is a method problem

## Reversible via

Drop the counter and the section; the timeout message stands alone
