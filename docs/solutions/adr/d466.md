# D466: Output the model did not choose to read whole passes one view

Status: accepted

## Decision

Output the model did not choose to read whole passes one view: a closed producer
list in code (a finished job's announcement and poll body, a cell traceback, %%bash
and !cmd output, a host-run check's tail, the child preview and the schema-failure
error), each reduced by the foreground bash reducer, lines clipped at 512 chars past
the 8,192 B floor, and cut at VIEW_CEILING 16,384 B with one row naming kept over
total, the cap and the call that returns the rest; one ceiling for root and child

## Why

The owner's priority that it should not matter which model runs; a recursion
traceback measured 54,916 B and a finished job lands raw in an <async_result> that
reclaim never cuts (reclaim.rs:320-326); stage 0's per-role report shows no child
window that needs a smaller ceiling

## Reversible via

Delete a producer's view() call and its Involuntary variant; VIEW_CEILING and the
clip width are one const each
