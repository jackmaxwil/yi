# D556: a child's token lease is enforced at the reply that crosses it, ending the...

Status: accepted

## Decision

A child's token lease is enforced at the reply that crosses it, ending the run as
`Failed { class: LeaseSpent }` rather than an interruption

## Why

The lease was drawn and settled but never held, so a child could spend a cap its
parent reserved for it, and the ending had to be a class of its own because an
interruption reads as the parent's choice

## Reversible via

Reversible in `ChildRecord::enforce` and `SubagentHost::lease_ending`, both in
`crates/runtime/src/subagent/`
