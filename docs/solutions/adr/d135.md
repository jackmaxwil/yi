# D135: landing is one verb and baselines merge themselves

Status: accepted

## Decision

Landing is one verb and baselines merge themselves: `scripts/merge_baseline.py` is
the git merge driver for `scripts/guardrails/baselines/*.json` and `schemas.lock`
(`.gitattributes` names it, `just land` configures it) — a ceiling merges to the
looser side and the schema lock to the union — and `just land` is the whole dance:
fetch and merge `origin/main` (anything the driver does not own is named and stops),
`just ratchet` in its own commit, the growth memo's number repriced to what
`check_growth` measures with its prose untouched, any decision row's missing ADR
rendered by `just adr`, then open, wait, merge

## Why

Eight of the eleven escapes of 2026-09-05 were not code but an agent landing by
hand, and the same day a ratchet commit swallowed code files and a merge commit
carried conflict markers, both while retyping baseline numbers a merge had
conflicted on. A baseline is a measurement, so a merge of two measurements has one
right answer — the one a re-measure can only shrink — and a driver gives it without
a person; the memo's number is likewise measured, only its prose is authored. The
driver is repository config, not versioned, so `just land` sets it every time,
idempotently

## Reversible via

Delete `.gitattributes` and the driver; `cmd_land` is `open` then `merge` again, and
the dance is a person's
