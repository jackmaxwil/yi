# D332: every same-repo PR is reviewed and none merges without its rounds (extends...

Status: accepted

## Decision

Every same-repo PR is reviewed and none merges without its rounds (extends D322 from
drafts to all PRs): the `review` job runs on each new head of any same-repo PR,
`just pr merge` refuses a PR without two rounds whose last holds for its head and is
not blocked, and `review` is a required check on main; a round holds for a head that
adds no commit beyond the reviewed one and the base (`pr_review.merges_since`), so
an update from main neither asks for nor triggers a new round

## Why

The owner's sanity check: of the last 20 PRs, every one opened without the `WIP:`
prefix (#884, #885, #891, #892, #895, #903) skipped review, and a non-draft PR
merged with no rounds

## Reversible via

Restore the `WIP: ` condition in `review.yml` and drop `unreviewed` from `cmd_merge`
