# D427: The console embeds a terminal pane whose PTY the console process owns,...

Status: accepted

## Decision

The console embeds a terminal pane whose PTY the console process owns, started
through a hidden `yi __pty <shell>` shim; YI_DESIGN.md §1.2 no longer rules out per-
pane PTYs in the console

## Why

The owner chose "Embed a real terminal pane" for the terminal button, and taking a
controlling terminal needs `setsid` and `TIOCSCTTY` between fork and exec, a
`pre_exec` closure that `forbid(unsafe_code)` refuses, so the child is the binary
itself, which makes both calls through safe `rustix` functions and execs the shell;
nothing crosses the daemon socket, so server-side terminal-frame streaming stays out
of scope

## Reversible via

Delete `PaneContent::Terminal`, `pty.rs` and the shim, and restore the §1.2 line
