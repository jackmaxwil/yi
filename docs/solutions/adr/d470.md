# D470: A word one edit from a verb, given alone, is refused instead of sent to the...

Status: accepted

## Decision

A word one edit from a verb, given alone, is refused instead of sent to the model,
and a verb that takes no words refuses trailing words

## Why

Haul CLI (cli-4): `yi doctr` ran a model turn and `yi undo the last edit` restored
files and ignored the sentence; section 17.1 said any first word is a prompt

## Reversible via

Reversible via deleting the no-words rows and the distance check
