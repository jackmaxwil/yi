# D589: Yi takes theme files

Status: accepted

## Decision

Yi takes theme files: `theme.dark` / `theme.light` name one of 104 shipped themes
(oh-my-pi's 100, MIT, credited in NOTICE, and four new ones) or
`~/.yi/themes/<name>.json` in oh-my-pi's shape, laid over the built-in palette on
the text, markdown, syntax, diff and status roles, and the console settings pane and
solo `/theme` preview it live and save it on Enter (amends §17.3 "The palette is
fixed"; D436's session-hued chrome stands, so borders, chips and thumbs keep their
hue; not a top-level feature, so §1.2 is unchanged)

## Why

The owner asked for themes and, on 2026-11-11, chose to ship the whole set, "Yes all
104 built in", which is also the visual approach gate's sign-off; the set is cut at
build time to the keys Yi paints and deflated, 261 KB of JSON to 25 KB

## Reversible via

Delete `crates/tui/themes`, `crates/tui/theme_keys.rs`, `theme_file.rs` and
`/theme`; config is strict, so a `theme` key must leave config.json before
`ThemeConfig` does
