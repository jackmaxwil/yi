# D122: the forge adapter is detection, not abstraction

Status: accepted

## Decision

The origin URL picks `tea` (any host) or `gh` (github.com), behind one `match`
and two functions each for open, poll and merge. A title reaches argv as
`--title=<t>`. `lanes.land` names a program the repository lands with instead,
the title appended, so yi's own tree lands through `just land`. Push and open run
in a background thread with a 30-minute bound.

## Why

A `Forge` trait would have one implementation per binary and no third. A title
starting with `-` was the model's one direct write to argv. `scripts/forge_pr.py`
already owns this repository's ratchet-commit-push-open-merge order and is not
reimplemented.

## Reversible via

Delete `lane/land.rs`; `/land` becomes the yi-forge skill's verbs typed by hand.
