# D510: a second question on the classifier sidecar, consumer `inject`, marks the...

Status: accepted

## Decision

A second question on the classifier sidecar, consumer `inject`, marks the text it
names as addressing the agent and never withholds it

## Why

The pilot separated subtle injections at a 0.8 cut with one false alarm in twelve
hard ordinary texts, and a false positive that withheld a page would cost the answer
the page carried, so the fence carries the score and lets the model weigh it

## Reversible via

Drop `classifier::Screener` and the `screen=` field from both fences
