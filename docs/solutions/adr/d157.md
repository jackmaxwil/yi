# D157: the runtime says what is there and asks when nothing moves

Status: accepted

## Decision

The runtime says what is there and asks when nothing moves: the environment block
carries `files: …`, the cwd's top level sorted, hidden names skipped, twenty shown
and `…(+N)` for the rest, a runtime fact that never enters the transcript or the
cached prefix; and when the todo list reads N/N and three consecutive turns made
only read-only calls (`read`, `grep`, `glob`, `todo`, `get_context`, or bash the
gate proves safe), one hidden `todo_nudge` per closed set says "Every item is done
and nothing has changed for three turns. Either `append` what remains and `start`
it, or write the final answer; call no other tools", counted as `closed_list_nudge`

## Why

never ran `ls`, so the checker the reference solution imports was never found; bun
zrejaEX re-marked one item done five times and html-js-filter WAygQAV re-proved a
finished job for 29 turns under a signature the D152 breaker cannot see
(docs/plans/2026-09-08-failure-paths.md §3.B, §3.E)
