# D569: A draft branch whose own copy of a workflow still carries a `runs-on` line...

Status: accepted

## Decision

A draft branch whose own copy of a workflow still carries a `runs-on` line the base
changed is merged with its base after ten quiet minutes, not two hours (amends D344
for this case only)

## Why

Review.yml moved to the llm runner on 2026-10-12 and ten branches that never merged
main kept running their copy on ubuntu-latest, holding five of six general runners;
a ready PR mid-landing must not be pushed to

## Reversible via

Delete stale_lane and the stale argument of decide in scripts/pr_autofix.py; D344
then applies unchanged
