# D570: a lane session's status row names the repo and the branch, each beside a dim...

Status: accepted

## Decision

A lane session's status row names the repo and the branch, each beside a dim label,
and the console shows the session id there too, so the row is the repo, branch and
id together (amends D435, which named the repo alone)

## Why

The owner, looking at the console chat, said the worktree name and the session id
were not marked and users could not tell what they were looking at; the row showed a
bare `yi` and a bare `01a1b3a9`, and a lane branch clipped from the left to the tail
of its uuid

## Reversible via

Restore the prior status-row layout
