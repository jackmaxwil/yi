# D552: `yi tool import just` writes into `~/.yi/tools` only, never a project's...

Status: accepted

## Decision

`yi tool import just` writes into `~/.yi/tools` only, never a project's `.yi/tools`

## Why

Project tools wait on hash-pinned trust (D30) and `discover_exec_tools` reads the
user directory alone, so a wrapper a clone could write would be arbitrary code
behind one prompt

## Reversible via

Reversible via adding the project directory to the importer and to the trust store
in the same change
