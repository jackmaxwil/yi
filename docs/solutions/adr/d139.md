# D139: the skills catalog is a ladder and a skill answers to its name

Status: accepted

## Decision

The skills catalog is a ladder and a skill answers to its name: the catalog budget
is 2 % of the model's context window in bytes, floored at 8 KB and capped at 32 KB,
and the fit clips descriptions to 120 then 60 characters before it drops any, then
lists the names past the budget on one `+N more:` line, so no skill ever vanishes
alphabetically; every skill compiles to a D54 rule whose needles include `$<name>`,
so a user who types the name gets the `skill://` pointer that turn whether or not
the skill declares a `trigger:`, and Yi's own skills (grid, review, session-mining,
assess, gate, debug) declare literal triggers on the text, the bash command or the
tool result they answer to

## Why

71 skills at 19,902 B against a fixed 16,384 B head-cut lost the last fifteen names
alphabetically, `yi-port` and `yi-tui-verify` among them, and a folded `description:
>` catalogued as `>`; D114's pointer mechanism had no user on this machine, and
YI_DESIGN §5's `$name` invocation was promised and never built

## Reversible via

Delete `catalog_budget` and the clip ladder (the fixed budget and `fit` remain), and
drop the `$<name>` needle from `skill_as_rule`
