# D462: A channel subscription with no adapter is peeked before it is claimed, and...

Status: accepted

## Decision

A channel subscription with no adapter is peeked before it is claimed, and an idle
one re-arms in memory with no claim record and no write (amends the section 15.2
'every mutation persists' contract)

## Why

An idle mailbox cost two fsynced ledger rewrites a minute per durable root; nothing
is delivered on an idle tick, so claim-before-deliver still holds where it matters

## Reversible via

Route every tick through claim_due_in_state again
