# D452: a Moonshot route (base URL host under kimi.com, kimi.ai or moonshot.ai, or...

Status: accepted

## Decision

A Moonshot route (base URL host under kimi.com, kimi.ai or moonshot.ai, or the
`kimi` provider) takes effort as a top-level `thinking: {type: enabled or disabled,
effort}` instead of `reasoning_effort`, sends the session id as `prompt_cache_key`,
replays `reasoning_content` on every assistant turn of a thinking model, and posts
an anthropic-protocol model to `/v1/messages?beta=true`; derived from the route,
never a catalog flag (D306)

## Why

Moonshot's chat API reads the `thinking` body field and validates thinking strictly
across tool turns (kimi-code kosong/src/providers/kimi.ts:495-560, llm-
kimi/trait.ts:82-117); Kimi caches by `prompt_cache_key` (trait.ts:87); the
account's ids are `k3.1-pro` and `k3`, so an id prefix would miss them

## Reversible via

Drop `compat::moonshot` and its openai.rs, anthropic.rs and replay branches
