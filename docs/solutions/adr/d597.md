# D597: reclaim counts a cut's rewrite as the route's own cache write price over its...

Status: accepted

## Decision

Reclaim counts a cut's rewrite as the route's own cache write price over its read
price when the catalog prices both, keeps ten reads for a route that prices cache at
zero (twenty on that route's hour cache), counts an hour-cache rewrite at twice
input over read, caps the ratio at 1,000 reads, and counts a cut's savings over at
most forty requests, not the requests so far (amends D558)

## Why

In one 211-turn Sonnet 5.5 session 34 cuts made 35 turns rewrite the whole
conversation, $9.11 of $18.61, because ten reads undercounts a 25-read write and a
long session made every cut easier to approve

## Reversible via

Revert the change: `rewrite_reads` returns `REWRITE_READS` and the horizon is the
requests so far
