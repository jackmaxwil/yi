# D153: a bare length stop forces the next turn to act

Status: accepted

## Decision

A bare length stop forces the next turn to act: the loop counts stops with reason
`length` and no tool call per prompt; the first and second push the D147 message
extended with "You are running a search by hand. Write the program that does it and
run it.", carry `details {rung, forced}`, and set the next turn's `tool_choice` to
the registered `bash` tool when there is one; the third ends the run; a length stop
that carried tool calls still fails them as before; `extract.py` counts
`length_forced`

## Why

The D147 text alone bought one compliant turn in five on row 0021; the 2026-09-08
probe showed this endpoint refuses to disable reasoning, the trials already ran at
the lowest effort the map offers (32,668 reasoning tokens on the spiral turn at
`low`), and a forced named tool call arrives with a few dozen reasoning tokens every
time (docs/archive/plans/2026-09-08-failure-paths.md §2)

## Reversible via

Delete `length_force` and `LENGTH_STOP_AT`; the counter returns to the D147 bool
