# D378: `compaction.at` makes a root session's compaction due once a request passes...

Status: accepted

## Decision

`compaction.at` makes a root session's compaction due once a request passes that
many tokens, when that comes before the window's reserve, and on a model whose
window is unknown; a value under `keep_recent` plus twice the reserve is raised to
it with a warning, since a compaction keeps that much and would otherwise run on
every request; unset or 0, the reserve alone decides as before

## Why

Compaction waited for the window minus 16,384 tokens, so on a 1M window the 43% of
Opus requests above 400k tokens carried 71% of its spend; making the threshold an
eval lever stays with #682

## Reversible via

Drop the `compaction` key and `Compactor::set_ceiling`
