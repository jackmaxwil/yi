# D562: `~/.yi/config.json` declares custom OpenAI-compatible providers under...

Status: accepted

## Decision

`~/.yi/config.json` declares custom OpenAI-compatible providers under `providers`,
merged into the catalog after the bundle and the cache, keyed by `apiKeyEnv`, a
literal `apiKey` or a token the yi-oauth store holds, refused at load when the id is
a built-in one

## Why

A local gateway that speaks chat completions could only be reached by overwriting
the `openai` catalog cache, which the next refresh rewrote within minutes

## Reversible via

Delete the `providers` key and its merge; a config carrying the key then refuses as
an unknown field, naming it
