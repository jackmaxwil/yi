# D432: the title's keys are the flat `console.titleIntro` and...

Status: accepted

## Decision

The title's keys are the flat `console.titleIntro` and `console.titleWeights`, not a
nested `console.title`

## Why

The settings page covers one level of nesting and every config leaf needs exactly
one row

## Reversible via

Add a nested `title` struct and a migration that reads the flat keys
