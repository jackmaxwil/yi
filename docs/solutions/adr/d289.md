Status: accepted

## Decision

`AGENTS.md` is tracked: ruler stops writing `.gitignore`, `check_agents_md.py` fails when a
`.ruler` rule is not in it verbatim, and `.ruler/090-workflow.md` says to commit it with the
rule. The instruction budget is 48 KiB, and an instruction file equal to one already attached
once HTML comment lines are ignored is skipped

## Why

A lane is a fresh worktree, so the gitignored ruler output never reached a Yi session there. In
the main checkout ruler's `AGENTS.md` (36,031 bytes) and `CLAUDE.md` differ only by
`<!-- Generated by Ruler -->`, so both attached and each was cut at 32,768 bytes, dropping
`097-landing` and `100-never` from both. The owner chose "Commit AGENTS.md" and "Raise the
limit" (#738)

## Reversible via

return the budget to 32 KiB and the dedupe to an exact hash
