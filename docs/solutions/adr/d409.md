# D409: a session re-reads config.json as it starts and re-derives every flag the...

Status: accepted

## Decision

A session re-reads config.json as it starts and re-derives every flag the command
line did not pin

## Why

"Instantly, like omp" was false while every process read the file once into a
OnceLock: a saved default applied only after a daemon restart; the owner chose "New
sessions pick it up"

## Reversible via

Restore the OnceLock and drop reload_config and refreshed from build_session
