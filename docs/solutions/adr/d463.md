# D463: A ledger write failure and an aborted lane reach the owning sessions as one...

Status: accepted

## Decision

A ledger write failure and an aborted lane reach the owning sessions as one notice
host note, deduplicated until a write succeeds or the error changes

## Why

Eprintln! under a raw-mode UI tears the screen and reaches no model

## Reversible via

Restore the two eprintln! calls
