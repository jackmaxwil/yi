# D75: Yi's behavior answers to a shrink-only ratchet

Status: accepted

## Decision

`baselines/behavior_baseline.json` lists faux-cassette-replayed cases and their pass states.
It runs inside `just check` on the zero-API tier only, and a formerly-green case going red
fails the build.

## Rationale

Yi's code cannot ship unmeasured, but its behavior — prompt files, tool descriptions,
thresholds, subagent briefs — was the last unmeasured surface in the repository. The unit of
learning is an eval case, not a rule: one occurrence suffices, cases do not rot, pass/fail is
external, and cases are commits. The OMP autopsy is the negative proof — every unmeasured
behavior store there devolved. CI cost is zero by construction because the tier is faux-only.

## Reversal path

Remove the gate line from `check_guardrails.sh` and delete the baseline. The cases remain
ordinary tests and keep running in the suite.
