# D318: a PR is reviewed in rounds

Status: accepted

## Decision

A PR is reviewed in rounds: a round is a comment from an allowed author whose first
line is `<!-- yi-round <n> -->`; `just pr review N` runs intake, one read-only `yi
ask --schema` per probe in `skills/yi/pr-review/probes/` on a model outside the
authors' family, and refuters that default to refuted; a finding needs its quote on
its line, a high blocks until `/override`, a call that does not answer leaves no
round; `MODE` ships `shadow` (docs/FORGE.md)

## Why

The last 80 merged PRs had one formal review

## Reversible via

Delete `scripts/pr_review.py`; posted rounds are inert
