# D445: a clean quit keeps a lane's session while its tree is dirty, and only reap...

Status: accepted

## Decision

A clean quit keeps a lane's session while its tree is dirty, and only reap and
discard clean a tree

## Why

Rt-lanes-1: release cleared the session, so the next claim ran checkout -f -B and
clean -qfd over uncommitted work, and a resume reset its own unmerged branch; D130's
tree rule held for crash orphans only

## Reversible via

Drop the release-side status read and the claim-side branch check; claim's tree
check alone still refuses the wipe
