# D149: done needs its check, and a number is computed in the kernel

Status: accepted

## Decision

Done needs its check, and a number is computed in the kernel: `Op::Done` with no
`evidence`, or blank evidence, is refused with `done needs evidence: the command you
ran and the line of its output that proves "<label>"` (`TodoError::NoEvidence`) and
nothing moves; one evidence still closes a phase or the whole list, and an open
parent or a stale counter is refused first as before. The doctrine's Evidence
section says a numeric answer is computed in the kernel (`ipython`) and pasted from
its output, never derived in prose

## Why

The schema and the doctrine both demanded evidence and nothing enforced it, so the
only witness was the mined `done_without_check`; on the v4 subset every near-miss
stopped one verification short of a numbered requirement, and foodstuff-beta-
activity's two misses were arithmetic done in the answer with the kernel called once
(issue #267). A refusal that names the evidence teaches in the tool result, so the
prompt gains no bytes for it

## Reversible via

Delete `NoEvidence` and the `evidence.is_none()` arm; drop the sentence
