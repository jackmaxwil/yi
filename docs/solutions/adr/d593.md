# D593: Spelling is Apple's NSSpellChecker, reached by a long-lived...

Status: accepted

## Decision

Spelling is Apple's NSSpellChecker, reached by a long-lived `/usr/bin/osascript -l
JavaScript` peer that yi-tools spawns through its `command` constructor (design §9)
and speaks one ASCII-escaped JSON object a line with a request id; the composer only
asks and polls a non-blocking cache, a peer that misses a 3 s deadline, desyncs or
cannot start leaves spelling absent, and nothing is downloaded, compiled or shipped
beside `yi`. Off macOS there is no checker and completion has the user's own prompt
words only, in solo and the console alike; a headless drive installs neither, so its
frames never depend on the machine. A late or dead peer turns spelling off for the
session and says so in one notice row, and the curl is written only where the
terminal advertises true color, a plain underline elsewhere

## Why

Owner 2026-11-11: "Can we use NSSpellChecker … so we dont need to download model?";
Rust cannot call AppKit without unsafe FFI, and a helper compiled in build.rs would
need release packaging, a target-arch build and a path found from `current_exe`,
where osascript ships on every Mac; measured on this Mac, 61 ms to the first answer
and 1.8 ms check, 2.5 ms complete, 3.7 ms guesses at the median

## Reversible via

Delete crates/tools/src/spell.rs and `Assist`'s engine; typos and Apple completion
then stay off
