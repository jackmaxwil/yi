# D119: the hand-back ladder is by move

Status: accepted

## Decision

`Lane::merge_into(self, ..)`, `discard(self)` and `release(self)` consume the
lane, so a second hand-back does not compile; the compiler is the test.
`land(&self)` repeats: pushed, then opened, then merged once the
gate is green. A dropped lane is handed back detached with its branch kept unless
merged; only the explicit release starts the warmer.

## Why

The B11 record enforced never-twice with a comment and a runtime `Running`
check. A moved value cannot be handed back again. `Drop` covers the exits that
`std::process::exit` skips only where the CLI calls release first, which is why
the CLI does.

## Reversible via

A `released` flag and a runtime error in place of the consuming signatures.
