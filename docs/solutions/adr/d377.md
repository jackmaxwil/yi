# D377: a write-billed route that read back fewer cached tokens than it wrote over...

Status: accepted

## Decision

A write-billed route that read back fewer cached tokens than it wrote over its last
10 requests raises one `cache_alert` per session, beside the two-total-miss tripwire
(amends D311); a request whose miss is a model switch, a stable-key change, a TTL
expiry or an upstream switch stays out of the window, since its cause is already
named

## Why

The old Sol alias read the same 20,872 tokens back on 22 of 23 requests while
writing 52k-90k each, 82% of that session's cost, and the tripwire never fired
because a partial read is not a total miss

## Reversible via

Delete `MissTracker::reuse_alarm` and the reuse window
