# D426: The console notebook pane drops its typing box, so its cells come only from...

Status: accepted

## Decision

The console notebook pane drops its typing box, so its cells come only from the
agent's kernel calls

## Why

The 3-row box hid the newest three rows of output, and the owner never types Python
there

## Reversible via

Restore the notebook input and its shift-enter route; `_yi/kernel_execute` stays
served for the Python client
