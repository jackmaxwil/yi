# D338: a flagged number costs one line, not a rewrite (amends D151)

Status: accepted

## Decision

A flagged number costs one line, not a rewrite (amends D151): `numbers_of` and
`extract.py`'s `claimed_numbers` skip code spans and a digit run beside a slash, so
a path fragment (`.ruler/040`) or a name in backticks is no claim; the send-back
names the numbers and asks for one line correcting only a wrong or unmeasured one,
or an empty stop when each is a name, a path or an id, and says not to restate the
answer or quote sources; `Cycle.awaiting_unsourced` is set with the send-back and
taken at the next stop, and an empty stop while it is set ends the turn without the
empty-stop redrive; identity.md's assessment shape stops asking every claim to cite
and every number to carry its command, and asks that numbers come from results run,
with sources named only where the reader will open them

## Why

Session 01a0f41f (glm-5.3-flash): the check flagged `040` from `.ruler/040`, the
send-back said "quote the tool result it came from", and the model wrote its eleven-
minute answer again with every number quoted; the owner said visible citations are
"noisy and hard to read", and on a patch-reply or answer tool, "Patch reply may be
brittle and come with negative downstream effects". An empty stop is the
acknowledgement because `last_assistant_text`, which feeds a child's answer to its
parent, mail and rpc, already skips an empty message; a literal `ok` would have
become the answer there

## Reversible via

Restore the old `unsourced_text` and bound, drop `awaiting_unsourced`,
`claimed_numbers` and the identity.md sentence
