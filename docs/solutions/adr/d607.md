# D607: A model role `models.rewriter` restates the composer's draft before it is...

Status: accepted

## Decision

A model role `models.rewriter` restates the composer's draft before it is sent,
behind a control on the composer's bottom border with the positions off, short,
medium and long; the rewrite is shown in the box before anything is sent, and the
host appends the typed words under it as `My words, verbatim:`

## Why

The owner asked for "auto prompt improvement" with "visible chrome and button
on/near the TUI composer. when button on, rewriter on" and "a slider or other picker
so i can pick more concise or longer", chose "Auto, show me first" and "Quoted at
the end, model sees it"; a ten-prompt trial showed a rewriter that reads the agent's
answers turns them into the person's orders, so it reads the person's own last three
messages only

## Reversible via

Unset `models.rewriter`
