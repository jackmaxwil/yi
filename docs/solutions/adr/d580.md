# D580: Yi may change its own prompts, levers and code only through a refine variant...

Status: accepted

## Decision

Yi may change its own prompts, levers and code only through a refine variant that
passes S0, the gate, and a better verdict at every stage, and lands as a pull
request the owner merges; YI_DESIGN §1.2 now excludes unattended skill creation or
self-modification instead of all refinement

## Why

The owner chose one gated loop over prompts and code with human-merged keeps, and
the old exclusion forbade the loop the evals already ran by hand

## Reversible via

Restore the §1.2 wording and evals/improve from this change's parent
