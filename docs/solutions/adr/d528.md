# D528: the agent-browser plugin runs its daemon outside the sandbox and its Chrome...

Status: accepted

## Decision

The agent-browser plugin runs its daemon outside the sandbox and its Chrome inside
one, with Chrome's own sandbox off

## Why

A Chrome outside read a planted ~/.ssh key and any contained program reached it over
its loopback debug port, so the agent-desktop shape was unsafe; the owner,
2026-11-01: "One yes, then web", accepting that a page breaking Chrome reads source
code and that contained programs can use the web session while it lives
