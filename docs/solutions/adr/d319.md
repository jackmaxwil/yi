# D319: a PR is reviewed in rounds

Status: accepted

## Decision

A PR is reviewed in rounds: a comment from an allowed author opening `<!-- yi-round
<n> -->`; `just pr review N` runs intake, one read-only `yi ask --schema` per probe
file, then refuters defaulting to refuted; a high blocks until `/override`, a silent
call voids the round, `MODE` is `shadow` (docs/FORGE.md)

## Why

80 merged PRs had one formal review

## Reversible via

Delete `scripts/pr_review.py`
