# D375: the model is shown the plan ops set, view and accepted_by_user, and a set...

Status: accepted

## Decision

The model is shown the plan ops set, view and accepted_by_user, and a set keeps the
rows it does not name (amends the whole-plan apply): a row's state carries every
other change, pending, running, done, blocked, failed or dropped, with a reopened
failed or blocked row retried or unblocked first, and a row's own todos are its sub-
steps; a row leaves the plan by state dropped or a struck checklist row, never by
omission; every other op stays readable, so a call written for the wider surface
still lands; accepted_by_user stays its own op because it asks a person; a `set`,
`supersede`, `decompose` or `append` with no rows is refused again, naming the one
call that would land, since reading it as a view hid a loop of eleven such calls as
eleven successes; a call with a goal and rows and no op is a `set`; a `set` whose
every row a rule left out is that rule's verdict; a `set` with a goal while no plan
is active opens a new one, and a delegation with no accept takes its contract's
critical check; rows with no op are a `set`, block fields beside its one row are
that row's and a row carrying `on` is blocked; a question with fewer than three
options is asked open instead of refused, in both tools; and the todo tool's `block`
on a plan's row is carried to the plan, as its `done` is; a finished plan admits
`set` beside `view` and `retry`, and the rows it reopens make it active again, since
its state is derived from its rows after every op; a row's fields sent at the top
with no op are that row's `set`, and a contract written inside a delegation is the
row's

## Why

The owner chose "Keep it", "Rows inside a row" and "Keep it a separate op" on
2026-10-06, after the fourth stage 5 run counted misread 14, stale 3 of 229 calls,
nearly all on ops other than set and view, and each run brought shapes the last had
not

## Reversible via

Restore the op enum to the first MODEL_OPS kinds, drop `keep_omitted` and `row_ops`,
and the set again deletes what it does not name
