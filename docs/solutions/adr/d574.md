# D574: the Claude Code memories of the working directory and of `~/.claude/memory`...

Status: accepted

## Decision

The Claude Code memories of the working directory and of `~/.claude/memory` import
into the store that owns their scope at session start, behind `memory.importClaude`
(default on) and tagged `source: claude`

## Why

The owner's memories were stranded in a shape Yi already reads, with only discovery,
provenance and staleness missing, and a session start is the one moment a session
reads memory

## Reversible via

Set `memory.importClaude` false, which stops the import and leaves the imported
notes in place
