# D342: the model reads bare only its requester's words (amends D25 and §4.4)

Status: accepted

## Decision

The model reads bare only its requester's words (amends D25 and §4.4): `Attribution`
gains `task` (the request a child, a reviewer or a one-shot call runs on; read bare,
never served by `user://`) and `host(source)` over a closed `HostSource` vocabulary
(`notice`, `restore`, `job`, `lifecycle`, `mail`, `landing`, `deadline`);
`convert_to_llm`, the one path every request takes, keeps a user message bare only
when `Attribution::reads_as_typed` holds (`user`, `task`, or `unproven` dated before
attribution existed) and fences every other user-role message, every `custom` kind
it does not wrap by name (under that kind) and both summaries (under `summary`) as
`<yi_internal_context source="…">`, the body's own fence tags escaped;
`AgentMessage::host_user` is deleted, so a producer chooses `user_input`, `task` or
`host_text`; the session's string `prompt`, `steer` and `follow_up` mint `task`;
`yi_context::project` dates an undated pre-attribution user message from its entry,
and the compaction floor keeps a truncated message's attribution; the environment
block is fenced as `environment`

## Why

The owner, on host text reaching the model as the user: "cannot be allowed". The
audit found it from about fifteen producers: custom kinds outside the wrapped list,
the session's host hooks (job reports, child lifecycle notices, plan-store and rule-
warning notices, the kernel restore block), the mail chase, landing failures, turn-
cap and last words, the summaries and the environment block; models answered such
text as "User asks" (session 01a0f41f). A rule at the one converter covers every
producer, current and future; the owner chose it over fixing producers one by one.
Ceilings: a `host(source)` tag on the wire is unreadable to a binary from before
this row; an undated `unproven` message stored after attribution existed is fenced
as `host` even if a test harness meant it as typed

## Reversible via

Restore `host_user` and the converter's passthrough of `User`, drop `Task`, `Host`
and `HostSource`, and the projection's dating
