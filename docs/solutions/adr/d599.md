# D599: The console and TUI model pickers offer only providers that hold a credential

Status: accepted

## Decision

The console and TUI model pickers offer only providers that hold a credential

## Why

An unkeyed provider's models were offered beside the ones the user can run, and
picking one only failed at its first turn; with no credential anywhere the whole
catalog is still offered so a fresh install can browse

## Reversible via

Call the unfiltered registry list in both pickers again
