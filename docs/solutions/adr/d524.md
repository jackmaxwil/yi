# D524: A feature-ledger edit is a line in the change file, applied by the recorder...

Status: accepted

## Decision

A feature-ledger edit is a line in the change file, applied by the recorder (extends
D342)

## Why

43 of 100 conflicted main merges touched a ledger row, a 2-4 KB line every feature
appends to, and clause-per-line files clear only 17 of those 43 because most row
edits replace text

## Reversible via

Let branches edit rows again by dropping the `ledger-edit` check; the lines already
recorded stay applied
