# D368: ripwire replaces grid as the code map Yi reads

Status: accepted

## Decision

Ripwire replaces grid as the code map Yi reads: the edit tool's post-edit check asks
`ripwire --edit-check` for each changed definition, `get_context` asks `--for` for a
task map and `--callers`/`--callees` for a symbol, the prompt card and the read-only
bash allowlist name ripwire's verbs, and grid's extension, seam, prompt, allowlist
and `grid_answer_empty` affordance are deleted

## Why

Grid is no longer developed ("Delete now"), it charted only Rust and Python and only
where a `.grid` chart already existed, and it could not start from a task in prose;
ripwire 0.6.5 parses 25 languages with no chart step, and on Yi put the fixed file
first for 14 of 25 recent commit subjects

## Reversible via

Restore `crates/tools/src/grid.rs`, `crates/runtime/src/ext/grid.rs`,
`prompts/grid.md`, `READ_ONLY_GRID`, the `grid_answer_empty` predicate, edge and
cassette from the deleting commit, and drop `ripwire.rs`, `ext/ripwire.rs` and
`prompts/ripwire.md`
