# D475: merge_worktree takes an opt-in check, run on the lane before it settles,...

Status: accepted

## Decision

Merge_worktree takes an opt-in check, run on the lane before it settles, through the
permission gate; a red verdict keeps the branch as a conflict does and records no
disposition, and the check's unignored writes are committed with the child's work

## Why

The fix-swarm recipe had no documented way to get the lane path (dogfood-
swarm-2026-09-30.md:110-111)

## Reversible via

Drop the check kwarg from the handler
