# D59: advisor promotion writes a rule file, not a permission pattern

Status: accepted

## Decision

`/advisor promote <advice-id>` (V11) compiles one delivered advice into a D54
rule file under `<cwd>/.yi/rules`: the trigger is the advice's target, the mode
is `gate` when the reviewer judged Hold and `remind` otherwise, and the body is
the advice text verbatim under a provenance line naming the advice it came from.
The file is parsed back with the same reader discovery uses and inserted into the
live rule engine, so the constraint binds the session that promoted it. The seam
is user-only: promotion is a TUI command with no host request behind it, so the
model has no path to installing a standing rule for itself.

## Rationale

V11 was written before D54 existed and named M4/M5 — a permission pattern or a
hold — as the target. Neither fits what the advisor actually produces. Prose
advice does not compile to allow/deny/ask: an M4 pattern keeps the verdict and
throws away the sentence that explains it, and the sentence is the part a future
session needs. M5 holds die with the session, which is the opposite of what V11
exists for ("the only cross-session persistence the advisor has"). D54's gate
mode already denies with evidence at the tool seam, so one standing-instruction
surface serves both cases instead of two.

The doctrine risk is real and is what shapes the seam: D54's thread is that the
runtime is a matcher delivering the *user's* words, never a reviewer installing
its own. Promotion is therefore a user act on advice the user has read, the file
says where the sentence came from, and it is ordinary markdown they can edit or
delete. Advice that names no target is refused rather than guessed at — a rule
with an invented trigger fires on the wrong thing forever.

Advice is retained before D28's headless degrade, so a Hold promotes as the gate
the reviewer meant even in a session where delivery had to soften it to a warn.

## Reversal path

Point `promote` at `ConfigRule` instead. The written rule files are inert
markdown once the engine stops reading them.
