# D615: Model auto-review is deleted, and `ask_user` is registered in every session...

Status: accepted

## Decision

Model auto-review is deleted, and `ask_user` is registered in every session with no
`request` argument (amends D81 and D389, and the §8 auto-review flow)

## Why

The owner chose it as the feature that leaves for `desktop/` (#2257) and asked for a
code cut; the classifier (D301) already settles what it can, so an auto-mode ask it
leaves open goes to the user, and with no reviewer there is no denial for `ask_user`
to escalate

## Reversible via

Revert by restoring `crates/runtime/src/auto_review.rs`, `ActionLedger` in yi-
permission and `models.autoReview` from the commit before this one
