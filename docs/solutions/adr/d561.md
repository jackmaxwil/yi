# D561: the edit side is the `[path#TAG]` headers a direct `edit` or `write` prints...

Status: accepted

## Decision

The edit side is the `[path#TAG]` headers a direct `edit` or `write` prints plus the
`ok` `edit` and `write` rows on a cell's `ipython` result, matched by path suffix as
before (revises D398)

## Why

A program's edit reached the session only in its cell's `calls` rows, so the read
whose tags the next edit needs was cut once it aged

## Reversible via

Delete the `ipython` arm in `reclaim::newest_reads`
