# D586: Five guardrail gates announce a skip in a checkout that has no...

Status: accepted

## Decision

Five guardrail gates announce a skip in a checkout that has no scripts/mirror and
stay failures in a source checkout

## Why

The public mirror omits scripts/mirror and the gitleaks scan fixtures, so bridge.py,
scripts/mirror/scan.py, check_scan.py, check_changes.py and record_changes.py
selfchecks failed there (the last two pin source commits the mirror's main lacks)
and a mirror contributor could not get just check green

## Reversible via

Delete the skip branches; the gates then fail in a mirror checkout again
