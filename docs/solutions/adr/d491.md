# D491: a reader whose answer fails its schema gets one tool-less retry carrying the...

Status: accepted

## Decision

A reader whose answer fails its schema gets one tool-less retry carrying the
validation error (the cold, text-history form on Anthropic over tool blocks),
widening #992 from a refused last-turn tool call to any schema failure

## Why

The tolerant parser alone leaves the recorded shapes refused

## Reversible via

Delete the retry in the shared completion path
