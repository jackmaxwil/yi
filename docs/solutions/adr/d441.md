# D441: With no Chrome or Chromium installed and no `browser.path`, the browser pane...

Status: accepted

## Decision

With no Chrome or Chromium installed and no `browser.path`, the browser pane runs
`yi plugin add chrome` once, off the frame loop, and launches Chrome for Testing's
headless shell 155.0.8059.39 from `~/.yi/plugins/chrome/`; the plugin table gains
`Shape::Tree`, a zip unpacked whole by an in-tree reader over `miniz_oxide`,
published by one rename after its member's sha256 matches, kept off PATH and out of
the prompt, and `yi plugin list --json` marks it `shape: tree` so the eval adapter
never carries it

## Why

The owner: "use installed chrome. if no installed chrome, download a pinned one on
first use", "Yes, download and pin (Recommended)" and "Install Chrome on the CI
runner (Recommended)"; reusing `yi plugin add` keeps one downloader, and the CI
image has no `unzip` to shell out to

## Reversible via

Delete the `chrome` row, `Shape::Tree`, `tarball::unzip`, `pinned::install_tree` and
the console's install state
