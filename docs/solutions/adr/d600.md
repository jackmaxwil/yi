# D600: provider `openai-codex` is compiled

Status: accepted

## Decision

Provider `openai-codex` is compiled: its client id, authorize and token endpoints,
loopback redirect `http://localhost:1455/auth/callback`, scopes and extra authorize
params live in the binary as a built-in `oauth-code` profile, like `cursor` (revises
D191 for `cursor` and `openai-codex`; a profile at `~/.yi/oauth/openai-codex.json`
still wins)

## Why

The owner asked for `yi login codex`, a ChatGPT Plus/Pro subscription login, and the
Codex CLI's public client registers exactly that redirect, so a user cannot supply a
working profile without copying the identity by hand

## Reversible via

Delete `crates/oauth/src/codex.rs` and its registry lookup, which restores D191 for
everything but `cursor`
