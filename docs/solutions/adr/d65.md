# D65: the subagent family gets a popup, and spawn attribution is observed

Status: accepted

## Decision

The subagent family gets a `BottomView` opened by `/agents`, never a fullscreen
dashboard. A child's spawning kernel cell is attributed by observation rather
than by a new wire field: the kernel call that is running when a child appears is
recorded as the call that made it.

## Rationale

§8.14 bans the alternate screen, so a 2,916-line reference agents view ports as
its row model and nothing else. What crosses over is the part that carries
information — the `├─`/`└─` connectors, the per-child glyph in that child's own
accent, own-usage token and call columns so the total is the sum of what is on
screen, the ten-cell context bar that turns warning at 80 %, and the in-row
confirm for stopping a child. What does not cross over is the frame around it,
because U11's popup primitive already provides a frame, and a second one would be
a second navigation model for the same data.

The spawn attribution is the interesting half. Yi's children are created by
`rlm.run` inside an `ipython` call, so the kernel call that is running when a
child appears *is* the call that made it. Stamping `ChildUpdate` with an
originating id would add a wire field, a schema shape and runtime plumbing across
the kernel boundary to learn something the UI can already see by looking at its
own state.

The observation is a heuristic, so what matters is which way it fails, and it
fails in the safe direction. A child born outside a kernel call carries no
attribution rather than a wrong one: the grouping row simply does not appear for
that child, and it sits at the top level where it belongs. A wrong parent would
be worse than no parent, because it would assert a relationship the reader has no
way to check.

The HUD header follows the same view: it stops saying `Subagents` and starts
saying `● 2 running · ◐ 1 idle · ○ 3 done`, dropping each count as it reaches
zero, so the header shrinks as the family settles rather than holding space for
states nobody is in.

## Reversal path

Drop the `Bottom::Agents` arm and the `spawn` field; the HUD, the task cells and
the children themselves are untouched.
