# D162: a clean stop is refused once when the record lacks the artifact or the...

Status: accepted

## Decision

A clean stop is refused once when the record lacks the artifact or the check, and
the second stop passes with a record: the todo coupling reads the prompt's product
paths (a token with a separator or a data or code extension after `write create save
produce output to at in called named` or in backticks, resolved against the cwd; one
that exists at prompt time is an input and is dropped) and the workspace's checker
(`test*.py`, `*_test.py`, `check*`/`verify*`/`run_tests*` scripts, a `Makefile`
`test:` or `check:` target, `pytest.ini`, `pyproject.toml` with `[tool.pytest`,
`package.json` with a `test` script, `Cargo.toml`; a script outranks a runner
marker); after the third tool turn with no named path on disk it delivers one
`todo_nudge` ("None of `…` exists yet. Write a first version now…"); at a clean stop
a named path still missing refuses once (`todo_intercept` reason `artifact_missing`,
rung 0) and then records `artifact_waived`, and a checker unrun since the last
landed write refuses once ("Run `<command>` and quote its result before stopping.",
reason `closure_unrun`) and then records `closure_waived`; neither fires on a turn
that called `ask_user` or while children run; `gates.artifact` and `gates.closure`
in the user config and `--no-gates` on `yi ask` turn them off; `extract.py` counts
`artifact_steer`, `artifact_refused`, `closure_refused`, `gate_waived`

## Why

On row 0023 every photonic attempt ended with no router on disk because the writes
were gated on a solution the reasoning never reached, and the near-misses (cargo
24/27, foodstuff 10/13, bun 27/36) stopped one check short with a checker in the
workspace they had not run since their last edit (issue #294); both facts are on
disk and in the tool record, so the gate is a data trigger, and a soft refusal keeps
the user's call that the harness never hard-blocks (docs/archive/plans/2026-09-08-pass-
levers.md S5)

## Reversible via

Delete `gate_redrive`, `artifact_candidates`, `find_checker`, the `Gates` config and
the flag; the `Cycle` fields go with them
