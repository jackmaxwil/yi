# D504: A note is refused for a key-shaped token that starts at a token edge and...

Status: accepted

## Decision

A note is refused for a key-shaped token that starts at a token edge and carries a
digit in its run, and for the <<<yi-external fence only; a <memory mention is
allowed (amends docs/memory.md)

## Why

Disk-backed-storage-layer was refused as an API key, and the only <memory producer,
D170's anchors, was struck by D278

## Reversible via

Restore key_run's anywhere-in-token find and loops' second clause
