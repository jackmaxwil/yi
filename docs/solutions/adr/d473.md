# D473: A tool-description cut owes no claims ledger when the new text is shorter...

Status: accepted

## Decision

A tool-description cut owes no claims ledger when the new text is shorter and every
sentence of it is a sentence of the old text, in order (revises D188's rule that a
changed key owes the claims ledger)

## Why

The request budget already fails only on growth, and in 22 days 48 commits moved
request_budget.json and 39 moved tool_surface.json, cuts paying the same sections as
additions

## Reversible via

Revert the PR; the lock's kept text is harmless
