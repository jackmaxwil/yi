# D56: plan transitions are the advisor's review moments

Status: accepted

## Decision

Naming `models.advisor` in config is what constructs the LLM reviewer; unset, the
advisor keeps observing and says nothing. Every host-verified plan write calls a
`PlanChangeHook` that requests a review at the next boundary and plants a one-line
frontier summary (`plan v3: 2 ready, 1 running, 0 blocked, 4 done of 7`) as the
digest chunk's context header. The poke is silent and still budget-gated, so it
can never overspend. PlanAudit as a separate V5 job is dissolved into ordinary
Advise.

## Rationale

D50 deleted per-call deterministic triggers, which left the advisor with cadence
alone. Task transitions restore a sparse, structural, meaningful cadence without
the runtime speaking: the deterministic layer only decides *when* to look, and
only the LLM reviewer has a voice. Tunnel vision — N calls against one task while
ready tasks sit unclaimed — is visible in that summary line and nowhere else.

PlanAudit had no remaining job: the shrink vectors it would have policed are
structurally refused (SHRINK_ERROR on edit, host-run checks on done), so a
separate speaking layer would be a voice with no gap to fill, which is exactly
what D50 removed.

## Reversal path

Drop the hook wiring in `attach_runtime` and the `forced` flag on the advisor
state; the advisor reverts to cadence-only.
