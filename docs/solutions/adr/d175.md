# D175: an in-band provider error is retried and settled like a dropped stream

Status: accepted

## Decision

An in-band provider error is retried and settled like a dropped stream: the
completions mapper marks a turn that ended on OpenRouter's `error` chunk with
`rawStopReason` `RAW_STOP_IN_BAND_ERROR`, one `"error"` const in yi-types that the
loop reads (a typed field would change the durable schema), and `nothing_delivered`
counts the mark beside generated tokens and a transport class, so an error chunk
that showed no text and no tool call sends D159's hidden `stream_retry`; the retry
count returns to zero after every turn that did not end in error, so each streak of
errors gets one retry where D159 gave one per prompt, and two in a row still end the
run; `run_request` settles the turn an error chunk ended from the generation record
(a stream that ends with no finish chunk at all still ends unsettled), as 0.206.0
does when the pump fails and D163 on a cut; a request span's `class` is read from
`errorMessage`, the content text only when there is none; the exit code is
unchanged, since under harbor's `pipefail` a non-zero exit scores 0 (amends D79,
D146 and D159)

## Why

On the 2026-09-09 night `Internal Server Error (upstream Wafer, code 502,
server_error)` arrived as a chunk, not a dropped connection: the turn carried no
usage and its text no transport token, so `nothing_delivered` read false, the run
ended on its first error with `yi ask --json` exiting 0 and the hour unused, and the
turn's usage stayed `unknown`, which voids the trial's cost under D79 and stops the
slice driver (the 2026-09-10 harness audit, B2); 0.206.0's settle ran only when the
pump returned an error, and its test fed the text to `mapper.fail`; D159's once-per-
prompt count left every drop after the first one fatal for the rest of the hour; and
a request span classed a failed request by its content text, which a dead stream
does not have, so an `HTTP 429` stop read `provider:error`

## Reversible via

Drop the `in_band` disjunct, the reset and the error-branch settle, and point the
span back at `text_of`; the const is the mapper's old literal and can stay
