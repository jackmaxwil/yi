# D384: the skills catalog clips every description at 60 chars and drops the file...

Status: accepted

## Decision

The skills catalog clips every description at 60 chars and drops the file path, its
header naming the clip and `yi://skills/<name>`

## Why

Measured on this machine's 39 `~/.yi/skills`: 7,682 bytes at the old 120-char-plus-
path rung, 3,153 clipped at 60, 614 names-only; 29 of the 39 declare no `trigger:`,
so a names-only index would leave them a bare name

## Reversible via

Set `DESCRIPTION_CLIP` back to a ladder and restore the path
