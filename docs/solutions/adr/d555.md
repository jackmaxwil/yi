# D555: the memory block is rendered once, at the first typed prompt, ranked by that...

Status: accepted

## Decision

The memory block is rendered once, at the first typed prompt, ranked by that
prompt's words with type weights and near-duplicate hooks dropped, its bodies inside
the byte budget the unranked index would have spent

## Why

Every session carried the whole index, so the model paid 335 tokens of a stored-note
map for a request no note addressed, and no body ever reached it

## Reversible via

Restore the `SessionStart` arm's index render and attach and delete the
`PromptSubmitted` arm
