# D188: a refused image read names the exact call

Status: accepted

## Decision

A refused image read names the exact call: `read` on a PNG, JPEG, GIF or WebP
answers `in ipython run \`print(await attach_image("<path>"))\` to put it in front
of the model`, with the path it was asked for, where it named only the bundled skill

## Why

Two v4 image tasks failed outright because the model never found `attach_image` from
the skill's name alone (the 2026-09-11 v4 sweep); the skill's SKILL.md gives the
call, but nothing opens it on a refusal

## Reversible via

Restore the skill-only wording
