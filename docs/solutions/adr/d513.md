# D513: a console sidebar session's second line is drawn only when it carries news...

Status: accepted

## Decision

A console sidebar session's second line is drawn only when it carries news (a state
that is not idle, a red gate, a todo list, a claimed question) or when the pane
behind it shows that session, so an idle row is one line and the workspace headers
and control rows wear the muted style instead of the text one

## Why

The owner asked on 2026-10-28 to "Reduce visual weight of the sidebar": two lines
per session doubled its height, and every idle session carried a state line reading
"idle · 7s" over bright chrome

## Reversible via

Restore the unconditional second line in
`crates/console/src/sidebar.rs::session_rows` and the `text` style on the control
rows and the bold workspace header
