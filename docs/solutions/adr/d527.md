# D527: every git the host runs goes through one door, by absolute path, with hooks,...

Status: accepted

## Decision

Every git the host runs goes through one door, by absolute path, with hooks,
fsmonitor and signing off

## Why

A host hand-back ran the repository's hooks, a relative core.hooksPath is written by
the child, and a tree's bin on PATH ran a contained write on the host

## Reversible via

Restore capture_named and git_capture to bare names
