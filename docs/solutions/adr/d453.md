# D453: every provider, catalog and login request Yi sends carries `User-Agent

Status: accepted

## Decision

Every provider, catalog and login request Yi sends carries `User-Agent:
yi/<version>`; a login profile's `stream_headers` may still replace it, and Yi sends
no `X-Msh-*` header

## Why

Yi identifies as Yi (owner brief); no agent set one, so ureq's default named the
HTTP library; Kimi Code's own UA product token is user-configurable (kimi-code
docs/en/configuration/config-files.md:405-415)

## Reversible via

Drop the `user_agent` calls and `yi_types::USER_AGENT`
