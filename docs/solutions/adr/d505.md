# D505: a newer push to main cancels the mirror run an older one started, instead of...

Status: accepted

## Decision

A newer push to main cancels the mirror run an older one started, instead of leaving
both runs to race the tip guard

## Why

The recorder's commit now starts a mirror run of its own, so one merge can have two
runs, and the older finishing last would force older history over the newer push

## Reversible via

Delete the concurrency block from mirror.yml
