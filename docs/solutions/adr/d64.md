# D64: a finished read-only call is deferred, not committed

Status: accepted

## Decision

A finished read-only call is deferred rather than committed on its own:
`read`, `grep`, `glob` and `find` accumulate and commit as one `Explored` cell
when the run closes, which is any other commit or `AgentEnd`. While the run is
open it renders in the live region. A run of one commits as the plain cell it
always was, and a failure never joins a run. Blank-line spacing moves with it:
separation is computed at commit time from the rendered height of the previous
cell, rather than emitted by each cell for itself.

## Rationale

Grouping cannot be retroactive. A committed row is in the terminal's own
scrollback and cannot be rewritten, so the choice is to defer or to never group
at all. Never grouping is what shipped, and eight rows of looking crowd out the
answer they were looking for: a transcript where the agent read four files and
grepped twice before editing spends most of its height on the search and almost
none on the change.

Deferral is safe precisely because the live region shows the open run, so nothing
is invisible while it is held — the reader sees the calls happening, they simply
land as one cell instead of eight. What deferral trades for is a timing failure
rather than a visibility one: a run left open when something else should have
closed it. That mode is bounded by `AgentEnd`, which closes any run
unconditionally, and a unit test caught the first instance of it immediately.

A failure never joins a run for the same reason a failure's body is never
mode-gated: a failed call is the one the reader must see, and folding it into a
count is hiding it. A run of one stays a plain cell because `✱ Explored ×1` is
strictly worse than the row it replaces.

The spacing rule moves for a related reason. Only the commit path knows what the
previous cell actually rendered, and now that a tool cell can be one row or
forty, no cell can decide its own separation from the one above it. Measuring the
rendered height at commit time is the only thing an append-only path can know,
and it produces the rule that reads correctly: a blank between two multi-row
blocks, a flush pack for a run of one-line calls.

## Reversal path

Drop the `explore_verb` arm in `commit_cell` and the height check in
`write_cell`; every cell commits itself as before.
