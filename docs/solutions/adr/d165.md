# D165: a parent reads its children's state as a fact of the environment, and every...

Status: accepted

## Decision

A parent reads its children's state as a fact of the environment, and every member
can read any member's tail: `rlm.status(name=None)` returns `{name, state, note,
tools, tokens, idle_s, worktree}` per child with `state` in `running`, `finished`,
`failed`, `needs_you`, `stuck`, read from the child's own records (`needs_you` when
its last assistant message called `ask_user` or a todo is blocked on the user;
`stuck` when its newest three entries carry a `repeat_break`, a `length_redrive` at
rung two or more, or a `todo_intercept` let go, or nothing moved for 300 s; the note
names which); a child that ends on `ask_user` reaches its parent as `[subagent d
asks: …] answer with rlm.send("d", "…", followup=True)` instead of `finished`; the
environment line becomes `children: 2 running (a, b) · 1 finished (c) · 1 needs you
(d: …) · 1 stuck (e: …)` whenever a child exists; `history://<agent>/tail/N` renders
the last N entries one line each and `history://<agent>/since/<seq>` everything
after a sequence; `rlm.maxDepth` in the config (default 1, ceiling 3) replaces the
constant and a family cap of sixteen live sessions holds across depths

## Why

The block showed `children: N running (names)` and nothing else, a child's question
read as a finished answer, `history://` rendered whole transcripts, and nothing
computed stuck, so a parent polling children read prose where a fact belonged (issue
#300; docs/archive/plans/2026-09-08-pass-levers.md S9); every state is a record the loop or
the coupling already wrote, so no model rates a child

## Reversible via

Delete `family.rs`, the status request, the ask notice, the tail selectors and the
config key
