# D546: the spec is the harness's object, not the model's

Status: accepted

## Decision

The spec is the harness's object, not the model's

## Why

A stop judged by prose passed 3/18 on the six-task slice while the checks failed on
one numbered requirement, and the one object that can say which id is red is a check
the harness runs

## Reversible via

Delete the `spec` tool and its store; the stop rule then has no verdict to consult
and the prompt's prelude has nothing to announce
