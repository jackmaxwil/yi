# D350: where a walled session's command does run on the host (yolo, every call on...

Status: accepted

## Decision

Where a walled session's command does run on the host (yolo, every call on Linux, a
yolo `exec://` source), it is refused when its text names a spill root, a session
store or a directory above one, save its own spill dir and transcript; this check is
text only and bypassable, a guard for an honest agent, and a contained call never
meets it

## Why

#1001: on Linux and under yolo nothing else stands between such a call and other
sessions' transcripts

## Reversible via

Drop `walled_root_refusal` from `host_wall` and from the tool seam
