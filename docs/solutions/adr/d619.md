# D619: a tool result that is not a file read, an edit, a search or a streaming...

Status: accepted

## Decision

A tool result that is not a file read, an edit, a search or a streaming write or
cell is drawn in one dim tone, never typed by its content, with the colour codes its
program printed dropped and no hue on its file paths

## Why

A shell card chose each row's colour from the row's own shape, so one `grep -n`
result showed grey context rows, white hit rows and magenta `--- label` rows
together; asked whether a program's own colours and the path hue should stay, the
owner answered "All grey, no exceptions"

## Reversible via

Reversible by restoring the `sniff(preview)` arm and `text_spans` in the tool card
body
