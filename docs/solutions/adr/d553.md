# D553: the dist binary size gate is removed, reversing D249/D424's measured ratchet...

Status: accepted

## Decision

The dist binary size gate is removed, reversing D249/D424's measured ratchet and
hard cap

## Why

The measured Linux ratchet failed merge-queue candidates whenever a batch grew the
binary past 16 KiB jitter (#1891 alone: 14,334,344 against 14,290,184, three
candidates in a row) and every growing PR needed its own baseline-only commit

## Reversible via

Restore scripts/guardrails/check_binary_size.py and its baselines from git history
