# D128: the model catalog is fetched, and the bundled one is its floor

Status: accepted

## Decision

The model catalog is fetched, and the bundled one is its floor: `yi_ai::refresh`
pulls models.dev's `api.json` for metadata and cost and each provider's own
`/models` list for the ids a key can reach, keeps their intersection, and writes
`~/.yi/catalog/<provider>.json` in the bundled files' own `{api: {id: Model}}`
shape; `Catalog::shared` overlays those files on the deflated bundle by `(provider,
id)`, so a cache entry wins and a missing, stale or corrupt file changes nothing. A
session whose provider is not `faux` and has a key spawns the refresh on a thread
when the file is older than `catalog.refreshHours` (24) and the two URLs pass the
wall; the running process never swaps its catalog — the next one reads the file. `yi
catalog` prints each file's age and `yi catalog refresh [provider]` forces one and
names the failure. Only the three providers with adapters are fetched; a models.dev
entry inherits the adapter, endpoint, compat block and effort ladder of its provider
unless the bundle already carries that id

## Why

The bundle was a snapshot: `openrouter/openai/gpt-6-astra` had been live on
OpenRouter for two days and was `unknown model` in yi until someone edited the JSON
and shipped a build. models.dev alone would list models a key cannot reach and turn
the refusal into a provider 404 at the first prompt; the provider lists alone carry
no pricing or context limits and the cost meter would run blind — the intersection
was chosen (user decision, 2026-09-05). The refresh is deterministic and data-
driven: a file age, a config number, no judgment loop. It applies to the next
session rather than swapping a `OnceLock` mid-turn because a model set that changes
under a running turn is a class of bug the picker, the MRU and the effort ladder
would each have to defend against. This revises D125: the deflated bundle stays, as
the offline floor

## Reversible via

Delete `crates/ai/src/refresh.rs`, the `catalog` verb and `spawn_catalog_refresh`;
`Catalog::with_cache` is one loop and `set_cache_dir` a `OnceLock` — the bundle
alone is what `shared()` returned before
