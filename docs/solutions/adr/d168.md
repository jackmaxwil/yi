# D168: a reasoning cut is not a length strike

Status: accepted

## Decision

A reasoning cut is not a length strike: the loop keeps D153's three consecutive bare
length stops and gives cuts their own count of twelve, a cut turn's re-drive from
the second consecutive cut says what to write (`write the first version of the file
the task names now, even a stub that runs, in one write call`), and the todo
coupling counts a cut turn beside a tool turn toward D162's third-turn artifact
steer, so a spiral that starts on turn two is told the path on turn three

## Why

In the 2026-09-09 slice run on 0.202.0 both finished photonic attempts read the
spec, wrote a todo and reasoned past 48,000 chars three times in a row; D153's third
strike ended each at turn four or five with no routing file, and the artifact steer
never fired because it was keyed to the third tool turn and a cut turn makes no tool
call; a settled cut costs about a third of a cent, so the strike that forfeited the
hour was the expensive part (issue #323)

## Reversible via

Restore the shared count and the tool-turn key; twelve cuts cost about four cents
