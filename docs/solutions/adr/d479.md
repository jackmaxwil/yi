# D479: An unpaged local

Status: accepted

## Decision

An unpaged local:// read and a grep page are cut by bytes as well as by rows, each
cut naming kept over total, the cap and the offset call

## Why

An unpaged local:// read returned the whole file and a grep page of 200 rows over
minified lines had no byte bound (the loud-caps law: a default window the model did
not ask for is a cap)

## Reversible via

Drop the byte stop and keep the row caps
