# D549: A contained member's kernel writes no family board, and its `kernel

Status: accepted

## Decision

A contained member's kernel writes no family board, and its `kernel://` objects read
as text

## Why

D240 granted the board to every child so D164's upward channel reached the root, but
the grant is also write access to the one directory the root's unconfined kernel
unpickles from, and the child it protects is exactly the one with a wall, a
container or a checkout of its own

## Reversible via

Restore the grant in `session_sandbox` and let `Resolver::dump_kernel` hand back its
path again
