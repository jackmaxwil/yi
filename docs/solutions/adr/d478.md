# D478: A console pane's kitty image ids are leased from a pool of 100 slots and...

Status: accepted

## Decision

A console pane's kitty image ids are leased from a pool of 100 slots and returned on
close; the 101st live pane draws text only

## Why

Haul UILIFE (console-2, #806): orb ids from the never-reused pane id reached the
avatar range at pane 100 and a close deleted a live avatar

## Reversible via

Reversible via widening the pool or moving the avatar range, as #806 first proposed
