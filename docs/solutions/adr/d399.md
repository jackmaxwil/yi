# D399: `tui-see gallery` renders every scene and label under a run root onto one...

Status: accepted

## Decision

`tui-see gallery` renders every scene and label under a run root onto one self-
contained HTML page (pictures inlined, each head run's cell diff beside its snaps)
that the owner reviews and comments on as one living artifact; `tui-see watch` keeps
a base run and reruns, rediffs and rewrites the gallery on every save under the TUI
crates; `--video` on the term host keeps the run as an animated WebP cropped to the
Ghostty window; the term host's proxy feeds its screen emulator with kitty graphics
(APC) stripped and treats `wait-idle` as a screen held still for a second with
digits ignored

## Why

The owner chose "One living gallery page" with comments routed back, and agents
iterate by saving; pyte printed kitty image payloads as text, which buried the rows
a wait looked for, and a once-a-second age label meant output never went quiet while
idle

## Reversible via

Drop `gallery`, `watch`, `--video`, `encode_video` and `ApcFilter`
