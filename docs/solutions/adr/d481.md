# D481: The kernel keeps IPython's default traceback mode; no xmode line is added to...

Status: accepted

## Decision

The kernel keeps IPython's default traceback mode; no xmode line is added to the
bootstrap

## Why

Measured in the live Yi kernel (IPython 9.17.1, Python 3.13.5): the unbounded
recursion cell is 73,479 B in Context, 45,988 B in Plain and 49 B in Minimal, and
the pandas KeyError cell is 2,504 B, 1,023 B and 18 B; Minimal is the only mode that
is much smaller and keeps the final exception line, but it drops the frame that
names the failing cell line, and it would change the KeyError output that must stay
byte-identical, while the view already takes the recursion traceback to 541 B

## Reversible via

Add `get_ipython().InteractiveTB.set_mode("Minimal")` to RLM_BOOTSTRAP_CODE
