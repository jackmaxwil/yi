# D506: Web search uses a provider-generic side completion, with models.webSearch...

Status: accepted

## Decision

Web search uses a provider-generic side completion, with models.webSearch defaulting
to openrouter/deepseek/deepseek-v4-flash and webSearch.engine defaulting to exa

## Why

The recorded DeepSeek calls were faster and cheaper than GPT-5 Nano with the same
five citations, and a side completion works with every primary provider

## Reversible via

Set models.webSearch to another OpenRouter model, or remove the built-in search
default
