# D363: every spend is a ledger record and every displayed total is a fold of the...

Status: accepted

## Decision

Every spend is a ledger record and every displayed total is a fold of the ledger,
set by the client and never summed; a side call (session title, branch summary,
compaction summary) records `LaneRecord::Usage` on the main lane with a cause naming
its job (`side:title`, `side:branch`, `side:compact`)

## Why

A title, a rewind's branch summary and a compaction summary billed the provider
while the session's cost total never saw them, because `complete_text` returned the
text and dropped the reply's usage

## Reversible via

Drop the three `book_side_call` calls and `complete_text` returns the text alone
again
