# Yi

A personal native-Rust coding agent: Pi's core shape and wire formats,
prime-agent's runtime (Jupyter kernel, context management, subagents,
heartbeats), OMP's hashline editing, and a redesigned advisor.

Status: phase 4 — pure loop; anthropic/openai/openrouter providers; v4
session store with resume; `yi ask` and `yi rpc`; core tools (bash, glob,
grep, write, hashline read/edit, ipython); permission modes with a
catastrophic denylist; context management with auto-compaction; MCP CLI
(`yi mcp`, config-gated: stdio + streamable-HTTP transports, OAuth
login/logout); Jupyter kernel runtime (uv-bootstrapped venv, verbatim
`rlm` Python package, host.request bridge) with `rlm()` subagents at
depth 1. Session files are byte-compatible with Pi's v4 format,
fixture-locked against files generated by Pi's own storage code.
Next: dill snapshot/restore (phase 4b), heartbeats + advisor (phase 5).

## Build

```
cargo build --profile dist -p yi-cli   # the shipping binary (target/dist/yi)
just check                             # fmt + clippy -D warnings + guardrails
```

## Use

```
yi ask --model anthropic/claude-opus-4-5 "prompt"   # needs ANTHROPIC_API_KEY
yi ask --model faux/faux-1 --json "prompt"          # offline smoke, event JSON
yi rpc                                              # LF-framed JSON command/event stream
```
