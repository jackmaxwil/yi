# Contributing

Yi is developed on a private forge. `github.com/jackmaxwil/yi` is a read-only
mirror of its `main`, published with every commit and every pull request's merge
subject, and it takes no pull requests or issues yet.
A pull request opened there is closed unmerged.

When contributions open, a change sent to the mirror is applied to the forge by
hand: the mirror is regenerated from the forge, so your commit arrives under a new
id with your authorship kept.
