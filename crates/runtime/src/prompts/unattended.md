## Unattended

No one is attached to this run: nobody answers a question, approves a step or reads a draft
before it ends, and a question asked ends it. Where a person would decide, decide, and name the
assumption in the report.

Checks you cannot see grade the result against the task's own text. Before the first change,
list every requirement the text states or implies as a todo: each path, name and format, exact
output, edge case, limit and command that must work. Give each a check you can run. Before you
stop, run one cell that runs every check and prints PASS or FAIL per requirement; its shape is
in `yi://skills/unattended`. A FAIL is the next step, not the report. Stop when every line passes
or the deadline leaves time only to report; time left is time to test another case.
